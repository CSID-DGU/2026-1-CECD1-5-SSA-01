# 포트폴리오

이 폴더는 AI 엔지니어 취업 포트폴리오용으로 정리한 자료를 모아둔 곳입니다.
프로젝트 본체의 기술 문서(`docs/`)는 그대로 두고, 여기서는 "무엇을 어떻게
문제해결했는가"를 채용 담당자가 빠르게 읽을 수 있도록 큐레이션합니다.

## 이 폴더의 자료

- [위원회 비용추계 TAG 룰엔진 — 케이스 스터디](./COMMITTEE_TAG_ENGINE_CASE_STUDY.md)
  RAG(유사 의안 검색)로 위원회 비용을 추계하려던 시도를 실측으로 포기하고,
  결정론적 룰엔진으로 피벗한 뒤 실제 정답지와 하나씩 대조하며 정확도를
  끌어올린 과정. LLM을 어디에 쓰고 어디에 안 쓸지(작업 범위 기준)를 실측으로
  가른 사례 포함.
- [평가 스코어보드](./평가_스코어보드.md) — NABO 정답지와 대조한 오차/판정
  표. 위원회_평가셋 50건 중 진행된 건을 계속 갱신 중(진행형 문서).

## 프로젝트 본체의 다른 포트폴리오 문서

같은 저장소 안의 `docs/`에는 이 프로젝트의 메인 분석 파이프라인("ORCA":

아래 문서는 위원회 룰엔진과는 다른 하위 시스템(미첨부 판단, 산식·선례 매칭)을
다룹니다.

- [엔지니어링 케이스 스터디(ORCA 전체)](../docs/ENGINEERING_CASE_STUDY.md)
- [오답 진단과 개선 기록(10 사이클)](../docs/IMPROVEMENTS.md)
- [타깃 제외 평가](../docs/EVALUATION.md)
- [개발일지(날짜별 원본 기록)](../docs/dev_log/)

`docs/IMPROVEMENTS.md`의 "사이클 7 — 국립대학병원법의 구조 오류"와 이 폴더의
케이스 스터디는 **같은 의안(2126334)을 서로 다른 두 파이프라인**(ORCA의
