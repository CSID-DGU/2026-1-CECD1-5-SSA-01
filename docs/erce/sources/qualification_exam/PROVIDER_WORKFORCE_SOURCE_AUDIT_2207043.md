# 2207043 제공인원 원자료 확인 기록

확인일: 2026-10-11

## 결론

비용추계서가 사용한 2021~2023년 발달재활서비스 제공인원 원관측값은 이번 공개자료 조사에서도 확보하지 못했다. 검색에서 확인되지 않았다는 의미이지, 해당 통계가 존재하지 않는다는 뜻은 아니다.

정답의 2027~2031년 전망치를 역산해 과거 관측값을 만들거나, 다른 집계의 인원으로 대체하지 않았다. 기존 `target_only` 전망과 새 의안의 인원 입력 요구를 유지한다. 이번 조사로 엔진의 변수 DB에 새 인원값을 추가하지 않았다.

## 확인한 공식 자료

### 사회서비스 전자바우처 주요 통계

- URL: https://www.socialservice.or.kr:444/user/htmlEditor/statistic/view.do?p_sn=15
- 대상기간 표기: 2025년 1월 1일~12월 31일.
- 정의: 기간 내 서비스 결제 이력이 존재하는 대상자·제공기관·제공인력.
- 발달재활서비스 행: 제공기관 2,843개소, 제공인력 14,183명.
- 품질 주의: 본문 제목은 2025년이나 제공기관·인력 표의 HTML caption은 2024년도라고 되어 있어 연도 표기 불일치가 있다.
- 사용 제한: 현재 공개 페이지의 결제 이력 인력을 2021~2023년 원관측값이나 비용추계서의 전체 제공인원과 동일하다고 간주할 수 없다. 등록 인력과 활동 인력의 포함범위, 중복 집계 여부도 추가 확인이 필요하다.

### 중앙장애아동·발달장애인지원센터 2023년 공시

- 게시물: https://www.broso.or.kr/hp/bbs/ViewCmpPosNttDtl.do?bbsId=0&bbsTyCd=02&cnterCd=01000001&nttId=1455&othbcAt=Y
- 17개 시도별 엑셀 첨부 목록을 확인했다.
- 서울 엑셀을 실제 내려받아 열 머리글을 확인했다: 연번, 시도, 시군구, 제공기관명, 사업자등록번호, 서비스구분, 제공영역, 2022년 단가, 2023년 단가, 단가변동, 단가상승률, 비고.
- 검사한 서울 파일에는 제공인원 열이 없다. 같은 기관의 영역별 행을 인력 수로 세면 안 된다. 다른 16개 파일의 내용을 검사한 것으로 주장하지 않는다.

### 법제처 2026년 입법영향분석 제안요청서

- 게시물: https://www.moleg.go.kr/board.es?act=view&bid=0010&list_no=147332&mid=a10504000000
- 첨부: https://www.moleg.go.kr/boardDownload.es?bid=0010&list_no=147332&seq=2
- HWPX를 내려받아 본문을 확인했다. 향후 자격제도 실태·통계 분석을 요구하는 과업 문서이며, 필요한 2021~2023년 인원 표는 제시하지 않는다.

### 공공데이터포털

- 발달재활·제공인력 검색을 수행했다. 확인한 결과는 제공기관 현황과 다른 사업의 인력 자료이며, 해당 기간의 전국 발달재활 제공인원 원자료는 확인되지 않았다.
- 자격인정자 누적수와 이용 아동 수는 필요한 전체 제공인원과 다른 지표이므로 사용하지 않았다.

## 다음 확보에 필요한 조건

보건복지부 또는 한국사회보장정보원의 2021·2022·2023년 발달재활서비스 인력 통계 중 비용추계에 사용한 모집단과 일치하는 자료가 필요하다. 연도별 수치뿐 아니라 기준일, 등록/활동 구분, 언어재활사 포함 여부, 기관 간 중복 제거 여부를 확인해야 한다. 기관 문의나 정보공개청구는 아직 하지 않았다.

원자료를 확보하더라도 비용추계서의 추세식은 별도 확인해야 한다. 정답의 미래 인원에 맞추어 회귀모형을 선택한 결과는 독립 검증으로 기록하지 않는다.
