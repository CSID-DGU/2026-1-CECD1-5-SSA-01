# ERCE 고정 산식 라우팅 트리

AI가 법안을 읽어 비용 항목별 트리의 말단 유형을 고르면 해당 등록 산식만 실행한다.
산식 선택에는 선례 검색이 필요하지 않다. 필요한 변수가 없으면 계산하지 않고 누락을 반환한다.
다른 산식으로 대체하지 않는다. 산식이 발견되면 같은 대분류의 하위 유형을 추가한다.

```text
물건비
└─ 정보시스템
   ├─ 사업계획금액사용 → 대상 사업계획 연도별 금액
   ├─ 운영
   │  ├─ 연간총액기반 → 연간 운영비 × 연도별 상승계수
   │  └─ 인력단가기반 → 운영인원 × 연간 인력단가 × 상승계수
   └─ 구축견적 → 미등록 (임의 운영비/수량단가 산식으로 대체 금지)
```

전체 트리 원본: `backend/erce/route_tree.py`.
7개 상위 분류: 인건비, 물건비, 이전지출, 자본지출, 조세감면, 세외수입감소, 출자출연.
구현은 비용유발 유형의 수동 AI 판정 입력을 받는다. 자동 법안읽기 모델 연결을 완료했다는 뜻은 아니다.

`estimate_routed_item`은 `route_path` 배열 또는 기존 `route_key`를 받는다.
상위 분류에만 도달한 입력·미등록 말단·경로와 route_key 불일치는 거부한다.
등록된 기존 general_cost_resolver 산식 모두에 ERCE 실행 연결을 제공한다.
연결 완료는 변수 DB/단가표 완비나 신규 법안 추계 정확도 보장을 뜻하지 않는다.

추가된 직접 산식 경로는 명시값 → 대상 실제자료 → 공식 기준 순서로 변수 입력을 받으며
선례 문서 선택을 호출하지 않는다. 기존 연구/위원회 등의 선례 변수 조회 동작은 유지했다.
`committee_components`는 위원회 구성요소를 직접 넣어 검색 없이 검증하는 경로이다.
일반 수량단가/검증금액 경로는 다른 유형이 미등록이라는 이유로 자동 대체하지 않는다.

이번 작업은 연결·트리 구조 및 단위 테스트다. 신규 의안 실행이나 단가 검색을 수행하지 않았다.

## 2026-09-27 후속 작업

위 문단은 최초 트리 연결 당시의 범위다. 이후 [재사용 변수표](ERCE_VARIABLE_TABLE.md)에
근거 ID 선택→로컬 DB 조회→입력 우선순위→계산을 연결했다.
추가 잎: 물건비/장례안장/유골함및명패, 자본지출/묘지조성.
둘 다 연도별 수량×해당 단가를 쓰되 서로 다른 업무 단가를 섞지 않는다.
[2211932 실행 기록](cases/ERCE_CASE_2211932.md)에 최초 실패와 보강 후 결과를 별도 보존했다.

추가 협의체 잎: 회의개최운영비(협의체 수×회당 비용×연간 횟수),
연간운영비(기준 연간예산×물가 상승계수). 둘 사이의 시간단위와 포함비목을 구분한다.
같은 업무의 연간예산이 있으면 임의로 회당 단가로 해석해 횟수를 다시 곱하지 않는다.
[2200936 실행 기록](cases/ERCE_CASE_2200936.md) 참고.

추가 국회위원회 잎: 운영지원사업비→기준 연간예산×물가 상승계수.
국회 위원회라는 이름만으로 민간위원 참석수당을 적용하지 않는다.
지원인력 보수·기관부담·기본경비는 기존 인건비 경로, 자산은 신설 첫해1회로 별도 연결한다.
인력 모델 선택 시 예결산 예비심사 권한·직급구성을 검토한다.
[2215199 실행 기록](cases/ERCE_CASE_2215199.md) 참고.
