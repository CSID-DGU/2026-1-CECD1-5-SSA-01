# 웹 근거 선택 및 비용추계서 생성

## 사용 흐름

1. 의안 PDF를 올리고 분석을 시작한다.
2. AI는 의안과 현재 DB에서 검색한 추계 방법·변수 후보를 읽는다. 적용 가능한 근거 ID와 적용 이유를 선택하며 새로운 숫자를 만들지 않는다.
3. 서버는 원문 인용, 산식, 근거 ID, 자기 의안 제외, 적용 연도·단위를 검증한다.
4. 사용자는 제시된 참고 가정을 확인한다. 부족한 값만 추가 입력한다.
5. 추계가 완료되면 **비용추계서 생성하기**를 누른다. 서버가 같은 근거와 산식으로 다시 계산해 결과·재정수반요인·전제 및 상세내역·검토사항을 작성한다.
6. **PDF 내려받기**를 누르면 서버가 재계산한 A4 문서를 직접 내려받는다. Markdown 내려받기도 유지한다.

질문 중에는 오른쪽 패널에 같은 변수의 DB 참고 후보를 최대 5개 표시한다. 서버가 산식·시점·메타데이터 적용 조건을 검사한 후보이며, 공식 기준과 최신 자료를 먼저 보여준다. 의미적 최유사도나 적합성을 확정한 추천은 아니다. 사용자가 대상·규모·근거를 확인해 클릭하면 근거 ID와 적용 이유를 계산 및 문서 생성 요청까지 유지한다. 후보가 맞지 않으면 **직접 입력하기**를 눌러 입력창으로 이동하거나 건너뛴다. 좁은 화면에서는 패널을 위로 배치한다.

## 2200703 연결 검증

- 개발 AI 역할을 수동으로 수행한 검증이다. GPT API 자동 판단 정확도 검증은 아니다.
- 선지급 도입 조문을 주 비용항목으로 선택하고, 기존 긴급지원 폐지는 기존 예산 차감으로 처리한다.
- 다른 의안 2201707의 근거 9개를 선택한다. 자기 의안의 비용추계서는 계산 입력으로 사용하지 않는다.
- 선지급 대상 전망 × 월액 × 지급 개월 − 기존 긴급지원 예산으로 계산한다. 회수 수입은 상계하지 않는다.
- 2026~2030 합계 3,216.806억원. 기존 비교 정답 3,216.81억원과 차이 40만원.
- 전원 신청·기존 정책 월액·DB 전망 기간은 확인할 참고 가정이다. 실제 시행연도나 최신 확정 지급기준이라고 설명하지 않는다.

## 자료 조회 시점과 연결 범위

웹 기본 조회 기준은 분석일 현재 DB다. 발의일 격리 평가가 아니며, 필요하면 개발 분석 입력의 `evidence_cutoff_date`로 과거 시점을 지정한다. 자기 의안 및 재사용 불가 자료 제외 조건은 유지한다.

일반 산식의 검토된 근거 ID 선택과 전달을 연결했다. 하위 변수 산정의 별도 모델 어댑터는 이번에 양육비 선지급을 연결했다. 다른 특수 모델의 가정 플래그를 무조건 생성하거나 모든 수동 성공 사례가 자동 연결되었다고 간주하지 않는다.

사용자에게는 한글 오류 안내를 반환하고, 기술 진단 정보는 서버 로그에 남긴다. 기존 화면 결과에는 새 연결 정보가 없으므로 수정 후 PDF를 다시 분석해야 한다.

## 원문 인용 확인에서 막힌 경우

GPT가 선택한 방법이 맞아도 신규 지급 조문 대신 삭제 지시만 인용하면 계산을 중단한다. PDF 공백·줄바꿈은 인용 검증에서 정규화한다.

양육비 선지급의 인용 오류에는 원문에서 신규 선지급 신청 조문을 찾아 **확인 후보**로 제시한다. 조문·페이지·인용을 원문과 대조하고 같은 DB 근거로 후보 계산까지 검증하지만 자동으로 수락하지 않는다. 사용자가 **이 조문으로 이어가기**를 누르고 참고 가정을 확인해야 생성 버튼이 활성화된다. 정답 PDF나 기대 금액으로 조문을 고르지 않는다.

기타 확인 오류에는 **PDF 다시 분석하기**를 제공한다. 계산 전에는 ‘계산된 금액’이나 ‘추계 완료’로 안내하지 않는다. 이 복구 기능은 AI가 매번 같은 분석을 한다거나 모든 조문 오류를 자동 해결한다는 의미가 아니다.

## 비용추계서 PDF

- `/api/erce/draft/pdf`는 브라우저의 금액을 신뢰하지 않고 입력·근거 ID로 다시 계산한 뒤 PDF를 생성한다. 누락 항목이 있으면 생성을 차단한다.
- 표지 → Ⅰ 비용추계 결과 → Ⅱ 재정수반요인 → Ⅲ 전제와 상세내역 → Ⅳ 부대의견 → Ⅴ 작성 정보의 구성을 사용한다.
- 양육비 선지급에는 가구·비율·자녀 수에 따른 대상 건수표, 월액·지원개월에 따른 급여지출표, 기존 예산 차감표를 넣는다.
- 2200703 개발 입력 예시를 정답과 비교했다. 7쪽 구성, 연도별 표시 금액·합계·연평균 일치. 정답 대상 산정·지출 상세표에서 추출한 쉼표 표기 숫자 41종이 모두 생성 PDF에 있었다. 이 검사는 값의 포함 검증이며 모든 문장의 동일성 검사가 아니다.
- 실제 생성 PDF를 이미지로 변환해 한글·표·페이지 나눔을 확인했다. 공식 문장의 완전 복제나 회수율 참고표의 재현은 하지 않는다. 작성 시스템과 초안 표시를 유지하며 공식 담당자·추계번호를 부여하지 않는다.
- 로컬에서는 AppleMyungjo를 사용한다. 다른 환경은 서버의 `ERCE_PDF_FONT`로 한글 폰트를 지정할 수 있고, 미지정·파일 부재 시 내장 글꼴로 대체된다.
