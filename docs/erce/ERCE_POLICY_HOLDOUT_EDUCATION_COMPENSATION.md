# 교육지원·보상 평가셋 (2026-10-02 동결)

각 10건, 총 20건을 `backend/generated/erce_policy_holdout_education_compensation_v1/`에 원문·비용추계서·메타데이터와 함께 복사했다. 원본 파일은 보존하고 개발용 `development_manifest.jsonl`에서는 20건 모두 제외했다. 기존 100건 검증셋과 별도이며 중복되지 않는다.

- 교육지원: 2204110, 2207745, 2220491, 2200630, 2207514, 2216306, 2207598, 2201928, 2216996, 2214005.
- 보상: 2204338, 2209615, 2217535, 2200750, 2214817, 2216274, 2214943, 2202670, 2217417, 2208085.

사례 문서가 있거나 현재 ERCE 변수 DB에 출처 의안으로 등록된 건은 선정에서 제외했다. 법안명·발의연도 분산과 고정 해시 순서를 사용했으며, 선정 시 정답 PDF 내용은 읽지 않았다. 기존 정책 분류는 휴리스틱 후보 분류이므로 확정된 순수 정책 유형으로 간주하지 않는다.

복사 파일은 원본과 SHA-256 일치를 확인했다. 개발 목록은 3,270건에서 3,250건으로 변경했으며 변경 전 목록은 평가셋 폴더의 `development_manifest.before.jsonl`로 보존했다. 카테고리 원본 폴더의 링크는 유지되므로 개발 자료 수집 시 반드시 개발용 manifest를 적용한다.

이후 이 20건의 정답을 산식·단가표·프롬프트 보강에 사용하지 않는다. 평가 시 대상 자신의 정답뿐 아니라 20건 전체를 검색·변수 근거에서 제외한다. 과거 전체 RAG DB에 해당 자료가 있었는지까지 감사한 분리는 아니므로 기존 검색 DB를 쓰는 평가는 별도 누출 확인이 필요하다. 이미 공유한 ZIP은 변경하지 않았으므로 기존 자료 이용자는 위 20건을 개발에서 제외해야 한다.
