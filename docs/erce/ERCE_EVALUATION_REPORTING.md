# ERCE 검증 결과 보고 기준

## 의안별 필수 보고

1. **된 것:** 비용항목 식별 개수, 산식 일치 여부, 변수 충족 개수, 실제로 계산 완료한 항목.
2. **안 된 것:** 누락 항목·변수 및 이유. 자료 없음, 자료는 있으나 연결 안 됨, 적용조건 미확정, 미래 규모 예측 곤란을 구분한다.
3. **정답 차이:** 같은 비용 범위·기간·단위끼리 항목별 금액과 합계를 비교한다. 전체 미완료이면 전체 오차를 보고하지 않는다.
4. **검증 성격:** 정답 열람 전 실행, 정답 열람 후 보강·회귀검증, 독립 평가를 구분한다. 수동 AI와 GPT API 실행, 웹 연결 검증도 구분한다.
5. **가정과 남은 검토:** 기준연도·전망 버전·인구 준용·지급률·부담 주체 등 검토할 가정을 남긴다.

## 오차0의 의미

오차0만으로 완전 완료라고 하지 않는다. 부분 항목 비교, 반올림한 표시금액 일치, 정답 수치 적재 후 재계산도0이 될 수 있다. 정답 자체가 거친 표시값이면 **‘정답 표시액과의 차이’**라고 표현하고, 정밀 원시금액 정확도로 해석하지 않는다.

‘이번 의안의 급여비 계산 완료’는 모든 해당 급여 항목의 산식·필수 변수·계산·출처가 확보되었다는 범위 제한 표현이다. 실제 가정의 타당성, 다른 의안 재사용 성능, 시스템 전체 완성을 보장하지 않는다.

미추계는 비용0이 아니다. 자료를 찾지 못한 개발 미완성은 미추계 선례로 덮지 않으며, 적용조건과 출처가 확인된 경우에만 근거 있는 미추계로 제시한다.
