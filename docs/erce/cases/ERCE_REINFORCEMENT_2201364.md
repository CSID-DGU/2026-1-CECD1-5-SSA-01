# 2201364 연간 정책영향평가 연구용역 보강

2026-10-10. **공식 추계범위 재현 완료.** 최초 금액 미산출·평가건수 단가를 요구한 판단은 유지했다.

## 유지 및 보강

기존 수량단가·평가단·실태조사 경로는 변경하지 않았다. 라우팅 트리에 `물건비 → 평가사업 → 정책영향평가 → 연간연구용역패키지`를 추가했고 `policy_impact_annual_contract`를 기존 수량×단가×연횟수 계산기에 연결했다.
단가는 정답24C1610 PDF3~4쪽이 인용한 과기정통부2024 기술영향평가 정책연구용역 예산2억원이다. 연간1개 패키지·연1회·기간동결 가정을 함께 저장했다. DB 변수746개·방법63개다.
이는 모든 개별 정책마다2억원이 드는 단가가 아니다. 유사 분석평가 과업과 연간 패키지 범위·가격동결·추계시작에 대한 설명을 확인해야 사용할 수 있다. 보고공표가 연구결과 활용 작업이라는 참고 범위를 설명하고 같은 작업비를 자동 중복 가산하지 않는다.
새로운 확정 계약견적은 선례가격보다 우선하며, 다른 과업으로 단가를 선택하거나 근거확인 없이 방법을 사용하는 것을 거부한다.

## 정답 확인 후 회귀

2025~2029년 **연2억원**, 총 **10억원**.
정답과 **연도별5/5개·총액 정확히 일치**, 실제 오차 **0%**다.
실제 의안 개발회귀와 자기선례 제외를 유지한 별도 유사 의안 웹 경로에서 금액이 일치했다. 최초성과나 독립 새의안 성능으로 기록하지 않는다.
방법과 단가는 비슷한 연간 정책영향평가에 과업·범위 확인 후 재사용할 수 있다. 개별 평가 건수·단가 근거가 명시되는 경우 기존 수량단가 경로를 사용할 수 있도록 유지했다.
