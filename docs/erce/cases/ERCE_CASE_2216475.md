# ERCE 사례 2216475: 서비스산업 발전 기본계획·위원회

## 정답 열람 전 AI 판정과 변수 선택

법안 제5조(5년 기본계획) → 물건비/연구용역/기본계획 고정 산식.
법안 제9~10조(중앙정부 정책심의위원회) → 물건비/위원회/구성요소입력 고정 산식.
실무위원회·센터·지원 등은 규모 미확정으로 보류.

기존 로컬 sidecar에서 2214690의 관련 항목을 발견했다.
계획·위원회 금액 관찰값은 있었으나 변수 evidence 행은 없었다.
AI가 해당 비타깃 원문(회답 2025-12-17)을 확인해 아래 변수 근거를 보완했다.
타깃 정답 2216475는 이 단계에서 열람하지 않았다.

- 계획비: 서비스산업 관련 법정계획 용역 3건(88·107·196백만원)의 추계 적용 평균 130백만원.
- 위원회: 민간20명(법안의 최대 위촉 인원과 같으나 **실제 인원은 가정**), 연4회, 회당25만원 동결.
- 변수 선정 이유: 산업 분야·업무·법안 위원회 정원/위촉 한도가 유사하고 타깃 발의 이전 자료.
  산식은 트리에서 먼저 결정했으며 기존 문서 전체 총액을 산식 대신 가져오지 않았다.
- 추계기간: 최초에는 2027~2031년으로 가정. 타깃 부칙 6개월을 고려한 시행 첫해 반영을 놓쳤다.

엔진 실제 결과(천원): 계획 `[130000,0,0,0,0]`, 위원회 `[20000,20000,20000,20000,20000]`.
합계 **230000천원(2억3천만원)**. AI 선택 변수는 `selected_variable_inputs`로 전달하고
선례 가정으로 표시한다. 출처 의안·회답일·출처를 요구하며 미래/자기정답 근거는 거부한다.
AI의 의미/규모 적합 판단 자체를 엔진이 자동 검증하는 것은 아니다.

## 정답 비교

정답: 26A0588, 회답일 2026-02-10.
원본: `backend/generated/assembly_22_validation_holdout_v1/by_bill/2216475/cost_estimate.pdf`.
2026~2030년 합계 **238000천원 이상(2억3800만원 이상)**.

계획 130백만원, 위원 수20·연간4회는 맞음. 차이:

1. 회당25만원이 아니라30만원 적용. 정답은 2026년 예산집행지침을 고려한 지급액 가정.
2. 첫해2026년은6개월분(2회). 첫 추계연도도 2027이 아닌2026.

총액 APE = |230000−238000|/238000 = **3.3613%**.
연도 시작이 달랐으므로 연도별 벡터가 일치한다는 주장은 하지 않는다.
총액 차이가 작아도 지급액·시행시점 두 오류가 상쇄된 결과이다.
시행연도만 고치고 수당25만원을 유지하면 220백만원으로 총액 차이가 더 커진다.
2026년 실태조사 기존 예산도 이전 자료의180백만원과 달리90백만원이었다.
이 값은 비용 0 판단의 자동 기준이 아니며 타깃의 기존사업 범위는 별도 검토 사항.

## 공식 기준 독립 확인 및 보강

기획예산처 2026년도 집행지침 원문 HWPX를 직접 내려받아 위원회 참석비 조항 확인.
