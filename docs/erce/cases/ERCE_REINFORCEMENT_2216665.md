# 2216665 보호아동 보험료 비중·장래인구 보강

## 유지·추가한 부분

정답을 보기 전 맞게 찾았던 연68500원 보험료·연1회·가격동결·2027~2031기간은 유지했다.
단일2024시설아동12482명 동결 대신 보호아동비중×연도별장래인구로 지원인원을 계산하는 경로를 연결했다.
경로는 이전지출 → 보호아동보험료 → 보호비중장래인구대리다.
기존가정위탁 지원분을 중복포함하지 않는다.

단가표에는2개행을추가했다.

- 공식2025가정위탁아동 연상해보험료68500원내외.
- 정답본문의2020~2024 보호아동평균비중 표시값0.17%.

보험료는 공식안내자료의 비교단가이며 시설아동의 실제새단체계약 견적은 아니다.
비중은 정답26C0846 PDF3쪽 표시값을 확보했지만 원5년시설관측·평균비중의 추가자릿수는 확인하지못했다.
역산한새계수를 저장하거나 표시0.17%를 원자료에서 독립재계산한 수치로 주장하지 않았다.

## 발견한 연령기준 불일치

정답본문 각주는 아동인구를18세미만이라고 설명한다.
그런데 저장된KOSIS2023.12중위추계의0~18세전망에0.17%를 곱해 사람수로반올림하면 정답인원11198/10838/10506/10128/9775가5개년모두재현된다.

0~17세인구로같은표시비중을 적용하면정답인원이되지않는다.
이것은정답표와본문의 연령범위가일관되지않는 강한정황이지, 원NABO산출파일을확인해 실제오류를확정한것은아니다.
정답숫자를맞추기위해 기본법적연령을0~18세로바꾸지않았다.

- 기본 under18_law:0~17세,같은표시비중의 보험료합계33.23621억원.
- under19_answer_reference:0~18세,승인된불일치메모가있는 reference_scenario에서만 허용.

새의안은법적연령·보호비중분모·실제보장대상을 먼저확인해야한다.
공식인구원자료에서양성별연령인구를 합산하므로 정답미래지원인원을 DB에 직접저장하지않았다.
동일버전자료가없는2032이후에는 인구를임의연장하지않고추가입력을요구한다.

## 실태조사 확대비 근거

보호아동을아동종합실태조사에추가하면 비용증가가능성이있지만 표본크기·선정방법·추가문항이미정이라는 정답PDF2쪽사유를방법DB에저장했다.
미추계는금액None이며0원으로합산하지않는다.
설계·표본·문항근거가확정되면 해당미추계판정을사용하지못하고 추가비를다시계산한다.
기존전체조사2026예산618백만원을추가보호아동조사비로복사하지않는다.
배상책임보험료는정답에도별도숫자가없어 상해보험료로완료했다고주장하지않는다.
