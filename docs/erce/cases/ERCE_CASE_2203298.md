# ERCE 사례 2203298: 경계선지능인 지원

## 정답 열람 전 실제 실행

원문 제7조의 기본계획(5년), 제8조의 실태조사(3년)를 각각
`research_plan`, `research_survey`로 선택했다. 두 산식은 등록되어 있었으나
보건복지부 도메인 단가가 없어 각각 `plan_unit_cost`, `survey_unit_cost` 누락으로 중단했다.
제9~16조 지원과 제17조 정보시스템을 규모 미확정 후보로 보류했다.
따라서 금액 오차율은 산출 불가. 주요 지원비 항목 선택도 불완전했다.

## 정답 확인

공식 문서: 의안 2203298, 추계번호 24C3255, 회답 2024-10-22.
원본: `backend/generated/assembly_22_validation_holdout_v1/by_bill/2203298/cost_estimate.pdf`.
2026~2030년 일부추계 합계 **186억 8,400만원 이상**.

- 기본계획 7천만원: 교육부 2021년 특수교육발전 계획 연구용역 준용.
- 실태조사 3억원/회: 보건복지부 2024년 해당 도메인 조사 예산 준용.
  기존 조사에서 3년 후인 2027년, 다음 2030년 시행. 첫 추계연도 2026년이 아님.
- 진단검사비: 6~11세 인구의 1% 지원, 1인당 20만원 가정. 기존 사업 1억 7,200만원/년 차감.
  지원비가 약 180억원으로 대부분을 차지한다. 최초 판단에서 계산 가능 후보로 골라내지 못했다.
- 제10~17조는 구체 사업/규모 미확정으로 추계 제외. 비용 0으로 확정하지 않는다.

## 보강 범위

1. 지원 경로 `diagnostic_test_subsidy`와 고정 산식
   `연도별 지원 대상자 수 × 검사비 − 기존 사업비` 추가.
2. 주기 연구 산식에 `first_occurrence_offset_years` 추가.
   주기만으로 첫 시행연도를 정하지 않고 기존 실시 이력으로 시작점을 지정할 수 있게 했다.
3. 같은 도메인의 기본계획·조사·진단검사 선례 가정 저장.
   자기 정답/미래 문서 제외 및 기관·도메인 조건 적용.
4. 검사 가정표에 업무·대상 연령·지원 규모 근거·3개 교육청 비교 예산 저장.
   지원대상자 수와 기존 사업비는 현재 법안별로 별도 근거를 요구한다.

20만원은 지방교육청 사업을 준용한 선례 지원액이지 공식 전국 검사요금이 아니다.
1%도 법정 비율이나 고정값이 아니다. 별도 공식 적용기준이 입력되면 선례보다 우선한다.
현재 조회는 정확한 도메인 조건이며 일반 의미 유사성/규모 검색 완성은 아니다.
정답 표를 확인한 뒤 저장했으므로 이 사례는 이후 순수 미사용 검증셋 집계에서 제외해야 한다.

## 정답 확인 후 재현 결과

지원대상자 수는 정답 표4의 `[22035, 20360, 18659, 17250, 16067]`를
재현 전용 입력으로 사용했다. 인구 전망→1%→대상자수 단계는 이번에 독립 검증하지 않았다.

단위 천원:

| 항목 | 2026 | 2027 | 2028 | 2029 | 2030 |
|---|---:|---:|---:|---:|---:|
| 기본계획 | 70000 | 0 | 0 | 0 | 0 |
| 실태조사 | 0 | 300000 | 0 | 0 | 300000 |
| 진단검사 지원(순증) | 4235000 | 3900000 | 3559800 | 3278000 | 3041400 |

합계 18,684,200천원, 공식 공개 합계 18,684,000천원.
총액 차이 **0.00107%**는 표시 반올림 수준.
이는 정답 확인 후 산술 재현이지 최초 추계 정확도가 아니다.
다른 지원 사업을 포함한 전체 비용을 산출한 것도 아니다.

## 2026-09-27 저장·연결 보강

지원 인원 전망은 해당 의안 전용 값으로, 기존 사업비는 당시 교육청 사업을 준용한
기준값으로 로컬 DB에 보존했다. 조사 최초 시행시점도 별도 저장했다.
계획·조사·지원비 모두 DB 근거 ID로 선택해 위 합계를 계산함을 확인했다.
현재 인구/사업 예산을 독립 확보한 것은 아니며 새 법안에는 해당 자료를 별도 검토해야 한다.
자세한 저장 정책은 [재사용 변수표](../ERCE_VARIABLE_TABLE.md) 참고.
