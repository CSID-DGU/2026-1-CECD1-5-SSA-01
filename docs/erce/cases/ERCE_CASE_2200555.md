# ERCE 개발 검증: 2200555 아동복지법 (우리아이자립펀드)

- 대상: 제44조의2 정부 월 적립 항목. 제44조의4 사업자 평가·교육 등은 이번 실행 범위에서 제외.
- 법안 원문과 현재 ERCE 변수 DB, 기존 `general_cost_sidecar_v1` 후보 데이터를 먼저 확인하고 계산을 시도한 뒤 정답을 열람함.
- AI 역할은 개발자가 수동 수행. API 호출 및 기존 DB 구조 변경 없음.

## 발의일 기준 검색 및 최초 실행

- 컷오프 2024-06-17, 자기 의안 및 미래 문서 제외.
- 기존 DB 변수 9,805건 중 날짜 조건을 통과한 2,101건을 조회. 변수명·근거문구의 `18세`, `장래인구`, `아동수`, `아동 수` 키워드 검색 후보 19건 검토.
- 전국 18세 미만 아동 수로 적용 가능한 숫자 시계열은 확보하지 못함. 출생아·65세 이상·국외 체류 아동·치과사업 참여자 등은 대상 불일치 또는 숫자 미저장으로 제외. 전체 DB의 모든 표현을 탐색한 완전성 보장은 아님.
- 현재 단가표의 전국 주민등록인구도 연령 조건 불일치로 제외. 직전 보강한 2200486 인구는 확인일이 2024-06-18이므로 원래 발의일 기준에는 사용하지 않음.
- 원문 3쪽 정부 지급액 `매월10만원`은 확정액으로 원 단위 환산. 보호자 적립금의 상한과 혼동하지 않음.
- 전년 12개월 지급 시나리오를 명시해 `calculate_erce_web_item` 실행. 필수 3개 중 2개 채움, 대상자 수 1개 부족으로 `needs_input` 반환. 정답을 보기 전 금액은 미산출.

## 현재 확보 자료로 재사용 시험

- 컷오프를 현재일 2026-10-02로 설정하고 2026~2030년 지급을 가정함. 자기 정답 2200555는 사용하지 않음.
- 직전 보강한 2200486의 전국 18세 미만 아동 전망과 연 12개월 지급 가정을 적용 조건 일치 사유와 함께 선택함.
- 지급액은 현재 대상 의안의 명시값 10만원 사용. 2200486의 최대 지급액 가정은 선택하지 않음.
- 경로: `transfer_child_asset_monthly`. 필수 변수 3/3 충족.
- 결과: 5년 **35.5332조원**. 정답 표시 합계 35.5조원 대비 **0.094%** 차이. 반올림된 전망 인구와 표시 총액 기준 비교임.
- **이 결과는 현재 확보한 다른 의안의 근거를 재사용한 시험이며, 발의 당시 블라인드 성능은 아님.**
- 이번 계산에서 기존 DB의 추가 채움 기여는 **0개**. 현재 ERCE DB에서 2개, 대상 의안 원문에서 1개를 사용함. 기존 DB를 자동 검색하도록 제품 코드에 연결한 것은 아니며, 수동 검색의 적용 가능성을 확인한 작업임.

## 확인된 문제

기존 DB에는 후보 숫자·방법론이 있으나 대상 인구 시계열이 `null`로 남은 경우가 있고, 출처·단위·적용 대상을 확인하지 않은 자동 추출 후보도 있음. 검색 보조로 활용하되 검수 없이 계산에 바로 연결하면 안 됨.
