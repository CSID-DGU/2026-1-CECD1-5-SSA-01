# 2212685 물가반영 확인 유형 연결

2026-10-06. 사용자 요청: 이번처럼 확인된 경우 물가반영으로 라우팅.

‘물가’ 단어만으로 모든 법안에2%를 적용하지 않는다. 물가반영 시나리오 확인(cpi_application_confirmed=True)과 근거메모가 있어야 이 하위 방법이 동작한다.

경로: 아동수당13세미만 확대 + 확인된 물가반영 → 신규월액에 전망률을 첫해부터 누적 적용 → 현행총액차감.

- 신규월액:20만원×1.02^(1~5). 현행10만원은동결.
- 기존공통인구에0~12세 합계의 코호트를 추가했다. 기존원자료 재사용, 새로운 대상인구를 가정하지 않았다.

- 기본급여 이미물가반영됨, 별도growth_rate나참여율의중복입력은차단.
- 적용확인/전망값이없으면2%를생성하지않고확인오류/필요정보요청으로반환.
- 다른전망값을공식/확인입력으로주면우선사용.2%영구하드코딩아님.
- 일반정답검증/웹에서대상의자기정답단가사용은차단하고, 개발사후확인모드만허용.
