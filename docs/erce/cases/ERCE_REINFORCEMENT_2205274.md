# 2205274 장애아동수당 의무화 순증 보강

2026-10-10. **공식 추계범위 재현 완료.** 최초 금액미산출 기록은 유지했다.

## 유지·보강

기존지급과 새지급의 순증만 구한다는 첫 판단은 유지했다. 이전지출→개인지원→장애아동수당의무화순증 전용 경로를 추가했다.
2024.11행복이음의 대상10,615명과 현재수급10,314명을 중증/경증×재가/시설4집단으로 분해해 저장했다. 단가는2024월22·9·11·3만원이며 연12개월 지급한다.
집단별 적격자−현재수급자를 계산해 [80,10,174,37]명, 합계301명만 신규지급으로 잡는다. 10,615명 전체에 급여를 다시 계산하지 않는다. 현재수급자가 적격자보다 많으면 거부하며, 확인된 실제수급값·지급기준은 참고근거보다 우선한다.
근거4개·방법1개 추가로 DB변수774개·방법69개다. 각세 전체인구나 성인장애수당에 사용하지 않도록 대상조건을 검사한다.
2024대상·분포·단가동결과2025~2029시작을 명시승인해야 적용한다. 만18세미만만 추계하며 재학18~20세는 정답 행정자료 추출한계로 제외한 범위임을 표시한다.

## 정답 확인 후 회귀

연 **4억6,500만원**, 5년 **23억2,500만원**.
정답과 **연도별5/5개·총액 정확히 일치**, 실제 오차 **0%**다.
실제의안 개발회귀와 자기선례 제외를 유지한 별도 유사 의안 웹 경로의 계산도 일치했다. 전원기존수급 시나리오를 주면 실제순증0을 반환하는 것도 검증했다.
이는 정답 확인 후 보강 회귀이며 최초실행·독립평가 성과가 아니다. 비슷한 의무지급안에 적용할 때 최신대상·기존수급·지급단가를 확인해야 한다.
