# ERCE 사례 2200563 — 민생회복지원금 지급을 위한 특별법안

## 정답 확인 전 최초 결과 (2026-09-28 고정)

- 개발용 의안. 별도 검증셋 100건에는 포함되지 않음.
- 읽은 자료: 의안 원문 `backend/generated/assembly_22_pdfs/by_bill/2200563/bill_text.pdf`와 2024-06-18 이전에 공개된 변수 DB 근거. 이 시점까지 대상 의안의 비용추계서는 열지 않음.
- 비용유발 조항: 제5조의 1인당 25만 원, 제1조·제6조·제7조의 2024년 한시 지급.
- 라우팅: `이전지출/개인지원/일반급여` → `transfer_recipient`.
- 산식: `TRANSFER_RECIPIENT_V1`, 대상자 수 × 참여율(기본 1) × 1인당 지급액 × 연간 지급횟수.
- 2024년 5월 말 전국 주민등록인구 51,277,347명: DB ID `mois:registered_population:2024-05`, 2024-05-31 공개. **국민 기준액 계산용 규모**이며 제5조 전체 지급 대상자와 동일하지 않음.
- 1인당 250,000원: 법안 제5조제1항 명시값.
- 지급횟수 1회: 2024년 한시 법안의 지급 절차·상품권 유효기간을 바탕으로 한 해석.
- 최초 실행 명령: `estimate_routed_item`에 위 경로, DB 근거 ID, 명시 단가·횟수, `start_year=2024`, `years=1`, `cutoff_date=2024-06-18` 입력.
- 엔진 산출 **국민 기준액**: `12,819,336,750천 원`(12조 8,193억 3,675만 원).

### 최초 결과의 범위·누락

제5조제1항은 교정시설·치료감호시설 수용자를 제외하고, 제5조제2항은 일정 요건의 외국인을 포함한다. 현재 DB에는 법안의 요건에 맞는 두 조정 인원 근거가 없다. 따라서 위 숫자는 **법안 전체 추계액이라고 확정할 수 없고**, `국민 기준액 − 제외 수용자×25만 원 + 포함 외국인×25만 원`의 기준값이다. 각 조정 인원을 임의로 0명이라고 가정하지 않는다. 상품권 발행·운영 비용도 법안상 재정지원 가능성이 있지만 별도 근거가 없어 미계산으로 남긴다.

## 정답 비교

정답: 의안 2200563 비용추계서(추계번호 24D0967, 회답일 2024-07-11), PDF p.2~6.

| 항목 | 최초 실행 | 정답 비용추계서 |
|---|---:|---:|
| 2024년 5월 주민등록인구 | 51,277,347명 | 51,277,347명 |
| 제외 수용자 | 근거 부족 | 교정시설 52,940명 + 치료감호시설 798명 = 53,738명 |
| 추가 대상 외국인 | 근거 부족 | 장기체류 1,881,921명 + 영주 185,441명 = 2,067,362명 |
| 최종 지급 대상자 | 국민 기준값 51,277,347명 | 53,290,971명 |
| 1인당 지급액 | 250,000원 | 250,000원 |
| 2024년 재정소요(천 원) | 기준액 12,819,336,750 | 표시액 13,322,743,000 |

최초 기준액을 정답 표시액과 비교하면 차이 503,406,250천 원, 절대오차율 약 **3.78%**다.
이는 일반 단가나 지급 횟수 오류가 아니라 **지급 대상 인원 구성 누락**이다. 정답 PDF p.5의
[표 2]에는 제외 인원 53,738명이라고 되어 있으나 본문 한 곳에는 53,739명이라고 적혀 있다.
52,940명+798명과 최종 인원 53,290,971명은 표의 53,738명과 일치하므로 표를 기준으로 비교했다.

상품권 발행비는 지자체별 증가 규모를 예상하기 어렵다며 정답도 추계에서 제외했다.

## 정답 확인 후 보강 (최초 성능에 포함하지 않음)

- `이전지출/개인지원/대상인구가감급여` → `TRANSFER_RECIPIENT_ADJUSTED_V1` 등록.
- 산식: `(기준 인구 − 제외 인원 + 추가 대상자) × 참여율 × 1인당 지급액 × 연간 지급횟수`.
- 주민등록인구는 기존 2024-05-31 공개 통계를 `base_population` 변수로도 연결.
- 제외 인원과 추가 대상자는 이 의안의 **2024-07-11 정답 비용추계서에서 확인한 개발용 관측값**으로 DB에 저장. 각각의 구성 수치·표 위치와 `target_only` 제한을 보존했다. 법안 발의일인 2024-06-18 이전에 알고 있었다고 간주하지 않는다.
- `evidence_mode="development_review"`, `cutoff_date="2024-07-11"`로 재실행한 결과: 대상자 53,290,971명, 2024년 `13,322,742,750천 원`. 정답 표시액과 250천 원 차이는 백만원 단위 반올림 때문이다.
- `holdout` 모드에서 해당 의안 자신의 정답 근거를 선택하면 엔진이 거부한다. 다른 의안에도 두 인원값을 전용할 수 없다.

따라서 보강 결과는 **산식·DB 연결을 검증한 재현값**이지, 독립적인 신규 의안 추계 정확도가 아니다.

### 정답 가정의 중복 가능성

법무부의 2023년 통계에서 장기 체류외국인 1,881,921명은 ‘등록외국인 및 거소신고자’ 기준이고,
영주자격(F-5) 185,441명은 등록외국인의 체류자격 하위 집단이다. 그러므로 정답처럼 두 수를
단순 합산하면 영주자 185,441명을 중복 계상했을 **가능성이 높다**. 법률의 장기체류자격과
통계의 ‘장기 체류외국인’이 동일한 모집단인지 원표의 분류 기준을 확인해야 확정할 수 있다.

영주자를 별도 가산하지 않는 대안 시나리오는 53,105,530명 × 250,000원 =
`13,276,382,500천 원`이다. 정답 재현값보다 `46,360,250천 원` 낮다.
따라서 정답 재현 수치를 범용 대상인구나 공식값으로 승격하지 않는다.
