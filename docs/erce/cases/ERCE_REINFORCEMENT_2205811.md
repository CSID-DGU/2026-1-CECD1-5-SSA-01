# 2205811 수어통역 증원 보강

2026-10-11. 같은 지원목적이라도 3인 서비스패키지와 1명 추가배치+장비취득은 다른 계산 구조다.

## 재사용 규칙

- AI가 국립대학병원 대상범위, 추가배치인지 전체운영패키지인지, 별도 집기가 필요한지 확인하고 해당 방법을 선택한다. 목적 키워드만으로 패키지를 선택하지 않는다.
- 순증인원 = 확인한 병원수 × 기관별 추가 통역사수. 이 선례는 이미 배치된 병원도1명 추가하며 기존지원기관을 차감하지 않는다. 이 가정을 사용자에게 확인한다.
- 연간 보수 = 순증인원 × 2024기준 직종연봉 × 기준년 이후 명목임금전망 누적계수. 일반 공무원 보수표와 구분한다.
- 첫해 자산 = 순증인원 × 2024기준 집기단가 × 첫해까지 CPI누적계수. 이후 연도0원이며 매년 반복하지 않는다.
- 18개·1명과 과거 전망은 적용성 검토할 후보이지 모든 병원의 고정값이 아니다. 명시값·현재실적·공식기준이 있으면 기존 변수 우선순위로 사용한다. 부족한 후보나 연도전망은 요청하고 생성하지 않는다.

## 근거와 한계

24C5381(2024-12-05)이 인용한2023.12 공공의료기관 현황,2024사회복지시설종사자 인건비가이드라인,2024.10 집기단가·전망을 구조화했다. 원자료 독립확인을 하지 않은 값은 `precedent_assumption`으로 유지했다.
임금2025 3.6%,2026 3.9%,2027~2030 3.8%; 집기CPI2025 2.1%,2026부터2.0%. 모든 비용에 일률2%를 적용하지 않는다.
선택한 자기 선례는 웹 holdout에서 차단된다. 다른 유사 의안 재사용 테스트는 별도 가상ID로 수행했으며 실제 새 의안 독립평가로 기록하지 않는다.
