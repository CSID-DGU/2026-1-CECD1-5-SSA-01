# ERCE 실행 — 2200509 아동수당법

실행일: 2026-10-02. 별도 검증셋 미포함 개발 의안. AI 역할은 대화 에이전트가 수행, API 호출 없음.

## 정답 열람 전

- 원문 전체 확인. 2024-06-14 발의, 2025-01-01 시행. 제4조제1항: 8세 미만 월 10만원 → 18세 미만 월 50만원. 제5항: 2세 미만 추가 급여 조항 삭제.
- 기존 집단 인상분은 `transfer_recipient_delta`, 신규 8~17세 지원은 `transfer_recipient`. 삭제 조항의 부모급여 감소는 별도 차감 대상으로 탐지했으나 0·1세 인구와 실제 지급액 부족으로 보류함. 원문의 '50만원 이상'을 실제 지급액으로 확정하지 않음.
- 로컬 DB 검색: 대상 자기 정답 제외, 공개일 ≤ 발의일 2024-06-14, 기간 2025~2029년 일치. 직전 보강한 2200147의 인구·지급률 3행을 선택하고 같은 사업·연령·지역·기간의 적용 이유를 기록함. 해당 근거의 공개일 2024-06-13은 발의일 이전임.
- 실제 엔진 실행: 기존 0~7세 대상 인구 × 지급률 0.972 × 월 인상액 40만원 × 12개월 + 신규 8~17세 인구 × 지급률 0.972 × 월 50만원 × 12개월.
- 연도별 금액(천원): `[36097747200, 34693401600, 33507172800, 32375764800, 31058899200]`.
- **아동수당 증가분만 167.7329856조원**. 부모급여 감소를 제외한 부분 추계이며, 전체 법안의 순증 총액으로 표시하지 않음.

## 이후 정답 비교

- 정답 회답일 2024-07-05, 추계번호 24C0465. 정답의 인구·지급률·아동수당 계산 구조는 선택한 선례와 일치.
- 정답 아동수당 증가분 표시값 **167.7조원**, 우리 **167.7330조원**: 표시값 대비 오차 약 **0.020%**. 반올림된 정답 표시값과의 비교이며 정확 원금액 오차가 아님.
- 정답은 0세 월 100만원·1세 월 50만원 부모급여 중단에 따른 감소액 약 **20.5조원**도 반영하여 순증 **147.3조원**으로 표시함.
- 부모급여 감소는 정답 열람 전에도 탐지했지만 자료 미확보로 계산하지 못함. 따라서 전체 금액을 맞혔다고 평가하지 않음. 부분 추계액을 전체 정답과 비교하면 약 13.9% 높지만, 이를 완료된 전체 추계의 오차로 보고하지 않음.
- 이번 실행에서는 대상 정답 값으로 DB를 보강하거나 재계산하지 않음. 후속 보강 대상은 0·1세 인구, 연령별 부모급여 지급액, 감소액을 합산하는 처리이며, 재원별 분리에는 부모급여 별도 국고보조율 68.34%가 필요함.
