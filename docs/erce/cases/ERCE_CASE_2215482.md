# ERCE 사례 2215482: 부동산등기 전자 열람·발급 수수료 면제

## 정답 열람 전

원문 제19조의 전자적 열람·발급 수수료 면제 → 세외수입감소/수수료변경 산식으로 선택.
공식 요금: 인터넷 열람700원, 발급1000원(열람과 증명서 발급 구별).
두 항목에 각각 공식값을 입력했지만 전국 이용 건수 `transaction_count`가 누락되어 중단.
최초 금액 및 오차율은 산출하지 않았다. 미계산을 합리적 수치오차로 평가하지 않는다.
최초 추계기간은 2026년부터로 가정했으나 정답은2027년 시작.

DB 조회에서 다음 자료는 부적절해 거부했다.

- 2212512 전세사기 사전상담55,847건: 전국 인터넷 등기 사용건수와 범위가 다름.
- 해당 자료의 증명서 발급700원: 열람과 발급 구분이 불명확하므로 공식 기준으로 재확인.
- 여러 등록면허세 감면 자료: 법원 수수료가 아닌 지방세여서 과목 불일치.

제67조의2 사용허가기간 등기 기록은 별도 기능개선 가능 후보로 보류.
정답 비용추계서는 이 조항을 별도 추계하지 않았다. 그 자체로 해당 비용0을 입증하지는 않는다.

## 정답의 비용 구조

의안2215482, 25D7080, 회답2026-03-26.
원본: `backend/generated/assembly_22_validation_holdout_v1/by_bill/2215482/cost_estimate.pdf`.

1. 시나리오1: 기존 전자 수수료 수입 2020~2024년 평균이 유지된다고 가정.
   공개 합계 **372,705백만원(3,727억500만원)**.
2. 시나리오2: 비전자적 발급50%가 전자로 전환하여 비전자 수입 감소분 추가.
   비전자2024년 수입6077백만원에 연-7.4% 전망, 전환율50% 적용.
   공개 합계 **383,110백만원(3,831억1천만원)**.

전자 사용량이 증가해도 이미 면제되는 전자 수수료를 신규 수입 손실로 중복 가산하지 않는다.
전환으로 잃는 비전자 채널의 기존 수입이 추가 손실이다.
기존1회 면제액도 수입표에 포함되어 있다는 각주가 있어 실징수액/기존면제액 구분은 별도 검토 필요.

## 보강한 트리와 데이터

세외수입감소/수수료면제 아래:

- 기존수입평균 → `NON_TAX_FEE_REVENUE_AVERAGE_V1`
- 무료채널전환반영 → `NON_TAX_FEE_CHANNEL_SHIFT_V1`

이는 특정 법안용 상수가 아니라 각각 평균/수입전환 고정 산식이다.
역사적 수입 및 전환율을 입력해 실행하며 필요한 입력 없이는 중단한다.
전국 수입액은 다른 사업의 단가로 재사용하지 않도록 타깃관찰 표에 격리했다.
전환율50%와 감소율-7.4%는 사례별 가정이며 자동 고정하지 않는다.
물건비/정보시스템/기능개선견적은 미등록 그룹으로 표시하고 임의 운영비 산식으로 대체하지 않는다.

공식 요금 표에는 서비스·채널·단위·시행본·확인일·출처를 기록했다.
국가법령정보센터 링크에서 2025-08-01 시행 제3222호 본임을 확인했고,
요금 내용은 법제처 생활법령정보 안내의 제2조·제3조 인용으로 확인했다.
원 조문 페이지는 웹 출력에 전문이 보이지 않았으므로 안내 내용을 넘어 원문 전문을 읽었다고 하지 않는다.

## 정답 확인 후 재현

정답 표2 수입값을 입력해 산식을 검증한다. 대법원 원자료를 독립 확보하지 않았다.
5년 평균은74,541.4백만원이며 정답 표시값74,541백만원과 반올림 차이가 있다.
금액을 맞추려고 표시액/연도별 상수를 산식에 하드코딩하지 않는다.
실제 실행 출력(천원):

- 시나리오1 `[74541400,74541400,74541400,74541400,74541400]`, 합계372,707,000.
  공개 정답372,705,000 대비 차이0.0005366%.
- 시나리오2 `[76954038,76775503,76610179,76457090,76315329]`, 합계383,112,139.
  공개 정답383,110,000 대비 차이0.0005583%.

두 차이는 평균·표시액 반올림 수준이다. 최초 신규 추계 성공이 아니라 산술 회귀검증이다.
관련 테스트46개 통과. 금액관찰값/평균/전환가정은 단가와 별도 유지해야 한다.

## 2026-09-27 저장·연결 보강

수입 관찰값·기준연도·전환율·감소율을 공식 수수료 단가와 구분해 로컬 DB에 저장했다.
금액을 수동 입력하지 않고 근거 ID 조회로 시나리오2 합계383,112,139천원을 확인했다.
원자료 독립 확보나 전환율50%의 실증 검증을 완료한 것은 아니다.
자세한 저장 정책은 [재사용 변수표](../ERCE_VARIABLE_TABLE.md) 참고.
