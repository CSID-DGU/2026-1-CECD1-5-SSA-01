# 2207600 관리비 지원 보강 — 참고 시나리오

2026-10-08. 최초미산출기록은유지했다. 첨부추계서 회답일2024-12-23이 발의일2025-01-17보다빨라 동일원문의전체정답이라고확정하지않는다. 버전불일치근거를참고사례로사용한다는확인이없으면DB선택을차단한다.

## 두 하위 경로

1. 체납가구지원: 임차일반+청년분리가구×체납률10.8%×공용관리비물가보정액×공공지원50%×12개월.
2. 전체임차지원: 전체임차급여가구×월3만원물가보정액×12개월.

중위소득48%이하의참고가구전망을저장하고,다른대상기준과매칭하지않도록했다.
공공임대거주42%를체납률에또곱하지않으며,국고83.61%는국비분할기준이므로전체금액에재곱하지않는다.
관리비는공용비이고전기·수도개별사용료를포함하지않는다.

DB에참고피연산자7개와공식2024물가실측1개를추가했다. 모두최신고시단가라고표시하지않았고,숫자총액을역산하지않았다.

시나리오1의기준단가:2023K-apt총월공용관리비46801000000원 /734547호 =약63714.09원/가구/월.
시나리오2의기준가격:월30000원을2024기준가격으로가정.
2025~2030은첨부표전망2025년2.1%,이후2%를시나리오별기준연도부터누적적용했다.

[통계청2024년연간소비자물가](https://www.kostat.go.kr/board.es?act=view&bid=213&list_no=434615&mid=a10301040200)에서2024실제2.3%를독립확인해2023가격의2024보정에만썼다. 이는회답일이후발표된관측치이지원추계가당시썼던전망값이아니다. 실측·전망을섞은참고가격시나리오임을기록했다.

누락값은요청하고,대상가구/공식기준등확인된입력값은선례후보보다우선한다. CPI·참여율·국고율중복적용을차단했다.
