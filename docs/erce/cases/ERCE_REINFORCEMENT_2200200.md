# 2200200 표준사업장 간접보조수요 보강

2026-10-10. 첫 실행의 직접국가출자 없음 판단·간접수요 미연결·금액미산출은 그대로 보존했다.

## 앞단과 하위 경로

AI 분석 지침에 민간공동출자·인증요건 완화가 직접국가출자는 아니지만 기존공공보조 신청수요를 늘릴 수 있음을 추가했다. 실제지원사업·신규신청·예산확대 조건을 확인 대상으로 남기고 임의지원금을 생성하지 않는다.
이전지출→표준사업장지원→요건완화신청증분 전용 경로를 연결했다.
2024일반/자회사형170개를2023지원74:64로 분해해 기준자회사형79개를 도출하고, 1/5/10%증가를 반올림한 매년추가1/4/8건을 산출한다. 매년고정증분이며 복리·누적기존사업장 재지원은 아니다.
2024평균지원2.95억원에2024.3전망CPI2025~2029를 적용한다. 이는 보조금평균이므로 투자금의3/4지원률이나10억원상한을 다시곱하지 않는다. 확인된실제추가신청건수는 참고신청률보다 우선한다.
신청증가와 예산확대는 참고가정이며 고정예산내배분이면 지출증가가 없을수있다. 예산제약완화를 승인하지 않으면 필요한확인을 반환한다. 이를 자동0원 또는 신규보조 확정액으로 처리하지 않는다.
인증·취소는 정답의 당시기존행정력으로 이행가능 판단을 별도로 저장했다. 새증원·외부위탁 필요가 있으면 이 근거를 적용하지 않는다. 설립보조의 간접수요와 구분한다.
근거8개·방법2개를 추가해 DB변수799개·방법76개다.
