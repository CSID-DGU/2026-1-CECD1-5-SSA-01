# ERCE 사례 2211932: 특수임무유공자 국립호국원 안장

## 정답을 보기 전 판단

2026-09-27 법안 원문만 먼저 읽음. 제5조제1항제4호마목은 사망한 특수임무유공자를
국립호국원 안장대상에 추가하며, 공포일부터 시행한다.

초기 일반 수량×단가 경로 실행은 수량과 단가 누락으로 중단.
기존 사이드카에서 같은 법률의 다른 의안 2212347을 발견하고 **그 문서만** 열었다.
해당 선례에서 사망자·행방불명자 및 부상자는 이미 자격이 있는 범위가 있어,
추가 대상은 특수임무공로자가 중심임을 확인했다. 부상자 중 기존 자격 밖 인원은
작다는 선례 가정을 검토하되 실제 0명이라고 확정하지 않는다.

추계기간은 2026~2030년으로 가정. 의안 2212347의 같은 집단 수량·단가를 DB에 저장해
선택하고, 일반 총사업비가 아닌 두 비용으로 분리한다.

- 물건비/장례안장/유골함및명패 → 연도별 추가 안장인원×안장용품 단가.
- 자본지출/묘지조성 → 연도별 추가 안장인원×묘지조성 단가.

수량은 선례의 연도별 추가 사망자 `[352,351,348,348,348]`에 안장률 45.8% 적용.
이미 사망한 공로자 1,597명을 5년에 분할 안장한다는 가정을 포함한다.
대상 법안에 명시적인 소급 조문은 없지만 '사망한 사람'에 시점 제한이 없다는 점에서
기존 사망자를 포함하는 시나리오로 우선 계산한다. 법적 적용범위는 검토 사항이다.

안장용품은 2025년 14만원에 연2% 상승, 묘지조성은 257만2천원에 연4.79% 상승.
모두 **다른 문서의 적용값과 전망 가정**이지 최신 공식 고정 단가가 아니다.
묘지조성에는 5만기 연천현충원 규모를 기록해 다른 규모 시설에 무조건 전용하지 않는다.

이 파일의 최초 입력은 정답 열람 전에 저장한다. 정답 열람 후 결과는 아래에 별도 기록한다.

## 최초 금액 — 정답 열람 전에 고정

로컬 DB의 `2212347:burial_quantity:2026-2030`,
`2212347:burial_supplies_unit_cost:2026-2030`, `2212347:burial_plot_unit_cost:2026-2030` 선택.
정답 숫자를 직접 넣지 않고 저장된 세 근거에서 계산했다.

연도별 금액(천원): `[457531,477444,495390,518458,542618]`.
5년 합계 **2,491,441천원(약 24.91억원)**. `evidence_mode=holdout`, 대상 문서 제외.
이는 의안 2211932의 정답 열람 전 금액이며 독립 검증 전 결과이다.

## 정답 확인 — 최초 실패 원인

공식 정답: 25D4154, 회답일 2025-11-19, 2026~2030년 합계 **206,000천원**.
정답 PDF p.3은 소급 적용 규정이 없으므로 2026년 이후 사망자만 추계한다고 명시한다.
같은 법률·집단이라는 이유로 소급 대상까지 빌려온 것이 주된 실패다.
최초 총액 오차율은 **1,109.44%**이며 성공 실적으로 집계하지 않는다.
두 비용 산식·기본 단가는 맞지만 수량에 포함되는 대상 범위를 잘못 골랐다.

## 보강 후 — 정답 수량으로 강제 일치시키지 않음

- 기존 사망자가 포함된 수량에는 `requires_retroactive_application=True` 기록.
  대상 법안의 소급 적용 근거를 입력하지 않으면 엔진이 선택을 거부한다.
- 같은 선례 2212347의 **신규 사망자만** `[32,31,29,29,29]` 분리한 수량 근거 추가.
  안장률45.8%와 두 단가는 기존 합리적인 선례값을 유지한다.
- 정답의 사망자 `[31,30,28,28,27]`나 새 공사비 상승률4.9%로 덮어쓰지 않았다.
  새 공식 자료가 독립 확인되면 별도 버전으로 보완하는 사항이다.

DB 선택→산식 계산 결과(천원): `[41594,42167,41282,43205,45218]`.
합계 **213,466천원(약 2.135억원)**. 정답206,000천원 대비 **총액 오차율3.62%**,
연도별 공개금액 기준 MAPE3.65%.
남은 차이는 선례의 신규 사망자 전망이 조금 더 많고, 적용 공사비 상승률도 다르기 때문이다.
정답을 보고 소급 범위 오류를 고친 **개발 재검증**이며 최초 미사용 정확도로 주장하지 않는다.
`holdout` 표시는 대상 정답의 숫자를 DB 입력에서 제외했다는 뜻이지 정답 미열람을 보증하지 않는다.

재사용 DB에는 2211932 정답 수량을 추가하지 않고 2212347의 분리된 수량·규모·단가만 유지했다.
