## 정답 열람 전 실행

- 원문5쪽을 읽고 제49조의4의 가족 자녀수3명→2명 확대를 재정수반 조문1개로 잡았다. 기존 운영 중 지원제도의 자격 확대이므로 재량 문구를 이유로 무조건 미추계하지 않고 실시 시나리오를 제안했다.
- 기존 `transfer_recipient_delta` 경로를 골랐다. 예상 산식은 **새2자녀 가정 대학생 수 ×(다자녀 지원액−이미 받는 일반 장학금)**이다. 법안이 전액지원이나 둘째부터 전액지원한다고 직접 규정한 것으로 판단하지 않았다.
- 이전2201899의3자녀 이상 가정 첫째·둘째 통계를 새2자녀 가구의 인원으로 전용하지 않았다. 소득구간별2024 평균 등록금과 지급액 역시2025정책 단가 및 신규 일반장학금 기준선을 대체하지 못하므로 선택하지 않았다.
- `analyze_erce_pdf(ai_draft=...)` 실제 실행: 인용1/1 확인, 비용항목1개, 미등록 경로0개, 필수 변수 **0/3**(대상인원·신규지원액·기존지원액), 금액 미계산. 공포 후3개월만 명시하여 시작연도 미정으로 남겼다.
- 입력·근거선택·부족 변수·실행 결과를 `docs/erce/first_runs/ERCE_FIRST_RUN_2209533.json`에 정답 열람 전에 저장했다. 이후 이 기록은 수정하지 않는다.

## 전체 계산을 위한 대학 구성비 보강 — 2026-10-03 후속

앞선 미완료 상태는 대상인원의 대학유형별 분포를 실제 통계로만 채우려 했기 때문이다. 정답에도 이 교차분포가 전부 제시되어 있지 않지만, **근거 있는 대리 가정을 명시한 초안**은 계산할 수 있다. 미확보 실제 통계를 확보했다고 표시하거나 정답 총액에서 역산하지 않고 아래처럼 보강했다.

- [국회예산정책처 「지방대학 육성정책 평가」(2025-08-21)](https://nabo.go.kr/board/file/down.do?fid=33318748)의 PDF35~36쪽, 본문14~15쪽 전국 대학 현황에서2024년 일반대 국공립425,003명·사립1,411,622명, 전문대 국공립9,755명·사립482,287명을 확인했다. 원문 PDF를 로컬에 보관하고 SHA256을 DB에 저장했다.
- 이 숫자는 보고서에서 재학생으로 표현되지만 교육기본통계 재적학생 총계와 일치한다. 휴학생 등을 포함하고, 교육대학·산업대학은 별도 미포함이다. 따라서 해당 법안 대상자의 **실제 분포가 아니라 전국 구성비 대리가정**으로만 적재했다. 일반대학 구성비를 일반·교육·산업대학 집단에 준용하는 한계도 표시했다.2024년 관측 버전이지 최신 실제 인원이라고 주장하지 않는다.
- 구성비는 국공립 일반18.2509%, 국공립 전문0.4189%, 사립 일반60.6193%, 사립 전문20.7109%다. 집단 총인원×구성비로4유형에 배분하고, 배분 합계가 원래 인원과 일치하는지 검증했다. 이미 유형별로 분할된 인원을 다시 나누는 입력은 거절한다.
- 대상집단2개×소득구간 묶음4개×대학유형4개, **32개 계산항목을 실제 ERCE로 실행**했다. 해당 법안의 정답 인원8개 시계열은 개발 회귀에서만 사용하며 신규 법안으로 재사용하지 않는다. 대학 구성비 후보는 출처·관측연도·한계·적용 확인 메모를 유지해 재사용할 수 있다.

### 지원 가정 차이는 숨기지 않고 분리

- 본문대로 모든 둘째를 전액지원: **7조9,875.88억원**.
- 현행 셋째 지원표를 둘째로 확대하여 신규·기존 모두9구간200만원 한도: **5조2,276.44억원**.
- 정답 표 참조 시나리오: **7조7,480.10억원**.

세 시나리오는 각각 완전히 계산되며 자동으로 정답과 가장 가까운 것을 선택하지 않는다. 이 차이는 단가 부족이 아니라 정책의 실시 방식 차이다. 실제 초안에서는 사용자가 지원방식을 확인해야 한다.

현재 **정답이 추계한 집단 전체의 계산입력 누락은0개**이고, 대리 가정으로 전체 초안 계산은 완료했다. 단, 신규2자녀 첫째는 정답 자체도 제외한 집단이므로 이번 총액에 포함하지 않았다. 법안 전체 모든 수혜자까지 추계했다고 주장하지 않는다. 정답 확인 후 재계산이지 독립 예측 성능이 아니다. 전국 구성비 근거1건을 추가하여 검토 변수는366건이며, 실제 통계·선례 가정·사용자 입력 우선순위는 유지한다.
