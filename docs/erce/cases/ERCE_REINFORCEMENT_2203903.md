# 2203903 미해결 범위 보강 — 전체 상태는 부분 완료

2026-10-09. 연구비1억8000만원/인건비3호미추계 재사용결과는 유지했다. 이번은금액보정이아니라인용과범위판정 보강이다.

## 해결

- 제31조분리청구 인용은6쪽이아닌7쪽에있어수정본으로 재검증했다. **새검증3/3통과**. 최초2/3기록은변경하지않았다.
- 원문제31조의직접급여범위는 **기존급여비중인건비/운영비의청구·지급구분**이다. 새정액급여를만드는조항으로처리하지않는다.
- 인건비수준변화/급여비증액은별도제32조의조건부미추계에서검토한다. 같은급여변화를분리청구비로중복가산하지않는다.
- 위두판단은시스템/행정구현비가0이라는확인이아니다. 원문상직접급여와구현비를분리했다.
- 부분금액오차0%여도별도항목미검토가있으면 **전체미완성·전체금액None·전체오차율None**을반환하는범위보고함수를추가했고이번의안보고에사용했다.

## 여전히미해결

|항목|필요근거|상태|
|---|---|---|
|분리청구시스템구현|기존기능확인서·추가개발과업/견적|검토필요,0원미확정|
|시정·감독행정|기존처리업무·순증사건수·추가인력/시간|검토필요|
|과징금수입효과|기존부과/징수실적·추가위반대상규모|검토필요|

공식사이트대상검색에서는해당법안의분리청구추가전산견적/예산근거를확보하지못했다. 검색미확보를‘자료가존재하지않음’이나‘기존업무흡수로0원’이라고해석하지않는다. 정답은이항목들을별도금액으로제시하지않아정답만으로채울수도없다.

## 재실행보고

- 조사계약부분1억8000만원,정답부분금액오차0%,연간5/5일치.
- 인건비조건부3호미추계재검증,금액None.
- 인용3/3통과(보강후).
- 6개검토범위중3개는판단/추계근거를정리했고3개는추가자료필요.
- **전체상태: 부분 완료. 전체금액과전체오차율은계산불가.**

이후같은유형에‘청구항목분리→새급여증액과구현비분리→기존기능확인→추가과업있는경우만추계’의검토구조를재사용할수있다.근거없는단가나시스템개발비를추가하지않았다.
