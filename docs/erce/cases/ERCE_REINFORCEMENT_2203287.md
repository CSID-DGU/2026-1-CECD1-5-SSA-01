# 2203287 지급액 기준 분리 보강

2026-10-09. **공식 비용추계서의 추계범위 재현 완료.** 최초 단가 미확정/금액 미산출 기록은 유지했다.

2026~2030년 연도별 표시 금액 5/5개와 총액 3,216.81억원이 정답과 일치한다.
계산 원값은 3,216.806억원으로, 실제 오차율은 0.00012435%다. 표시 금액의 일치를 원값 오차 0%로 보고하지 않는다.
별도 원문 기준 모드의 자료 부족은 이번 정답 재현의 미완료 사유가 아니다.

## 정답 정액 가정 모드 — 재현 완료

정답24C3127이택한정부계획월20만원을 **승인필요참고단가**로저장했다.
원문에표준양육비를고려하라는기준이있음을표시하고,정책정액가정을선택했다는확인과차이설명없이는사용하지못한다.

기존대상필터/지원개월/기존긴급지원예산차감산식을재사용했다.새금액에맞춰단가/대상비율을역산하지않았다.
재실행 **3216.806억원**,정답 **3216.81억원**,해당범위오차 **0.00012435%**.
이는표준양육비에서월20만원을계산했다는뜻이아니라정답의정책참고시나리오를재현한것이다.

## 원문 기준 모드 — 계산 경로 연결, 실제 자료 미확보

연령/부모소득구간별표준월액에가산/감액요인을적용한뒤채무자소득/부모합산소득을곱하고,대상구간구성비로평균월액을도출한다.

실질양육비 = 표준월액 + 확인된개별조정액.
채무자부담월액 = 실질양육비 × 채무자소득/부모합산소득.
평균월액 = Σ(구간별채무자부담월액×구성비).

계산된평균월액을기존선지급대상/예산차감계산기에연결했다.
실제표/조정요인/구성비가없으면필요정보를반환하고,월20만원으로대체하지않는다.
구성비합계1검증·분모0·부모소득보다큰채무자소득·음수실질비·정액월액의중복입력은거부한다.
합성자료로계산경로를검증했지만실제해당법안의표준액/구성비는아직확보하지않았다. 합성숫자를DB실제단가로저장하지않았다.

## 저장과 범위

DB에정답정액후보1개와기존대상근거의원문모드별칭8개를추가했다. 별칭은원출처/날짜를유지하며가격데이터를새로생성하지않았다. 방법2개로모드와적용근거를분리했다.

**정답이계산한급여범위의정액시나리오재현은완료**.
별도 원문 기준 모드의 실제 표준액 계산 및 추가 재정효과 검토는 남아 있다. 전체 법안의 모든 효과를 계산했다는 뜻은 아니지만, 이를 이유로 공식 추계서 재현을 미완료로 표시하지 않는다.
정답확인후보강회귀이므로독립성과로기록하지않는다.
