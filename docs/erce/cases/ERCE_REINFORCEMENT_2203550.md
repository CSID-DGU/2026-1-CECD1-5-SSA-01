# 2203550 공익활동형 최저임금 참고시나리오 보강

2026-10-10. 원문에 따른 임금차액·첫해2개월 방향은 유지했다. 라우팅에 이전지출 개인지원의 `노인공익활동최저임금차액` 전용 하위를 추가하고 참여자 및 최저임금 추세·월29만원·30시간·11개월·부대경비를 연결했다.
2019~2023 참여자 CAGR과2021~2025최저임금 CAGR을 사용하되 알려진2024·2025임금은 직접 사용한다. 부대경비는 현행·개정 양쪽 동일하게 적용하여 차감한다. 최저임금이 현재 지급액보다 낮아도 급여를 깎지 않는다.
첨부24C2515는 회답일이발의일보다빠르고표지의안번호가공란이다. 각 DB행에 버전불일치를 표시했고 명시적 참고 사용 승인·차이 설명 없이는 계산할 수 없다. 최신 실적이나 확정대상 정답으로 표시하지 않는다.
참고자료의2024~2028 총액9574억원 대비 재실행 **9573.621억원**, 실제 오차 **0.00395864%**, 연간억원표시 **5/5개 일치**다. 6개 근거·1개 방법을 추가하여 DB변수752개·방법64개다.
공익활동형만 참고 적용하고 이미최저임금 이상인 사회서비스·민간형에 중복 가산하지 않는다. 정답 확인 후 첨부자료 참고회귀로 기록하며, 확정대상정답을 맞힌 독립 성과가 아니다. 최초 기록은 유지했다.
