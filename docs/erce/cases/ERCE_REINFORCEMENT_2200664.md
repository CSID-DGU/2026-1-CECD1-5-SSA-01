# 2200664 장애인 근로자 최저임금 차액보조 보강

2026-10-10. 최초 금액미산출 및2025시작후보 기록은 유지했다. 고용사업주지원→장애인최저임금차액보조 전용 경로를 추가했다.

## 재사용 구조

직업재활시설 적용제외 근로자2019~2023실적·시설전체평균 시급·월근로시간 실적을 각각 저장했다. 대상수와 시급은 각각CAGR로 전망하고 월시간은 평균116시간, 지급기간은12개월로 가정한다.
최저임금 적용제외집단만의 시급·시간 실적이 부족해 시설전체평균을 대리 사용하고 다른사업체는 제외한다는 한계를 설명·승인해야 적용한다. 연계법안2200660 의결·시행 가정도 확인한다.
[고용노동부2024-50호2025고시](https://www.minimumwage.go.kr/customer/notice/view.do?bultnId=4555)의 공식시간급10,030원을 기준가격으로 저장했다. 2025상승률1.7%를 이 기준에 다시 적용하지 않는다. 2026~2030은 정답의2024.7NABO 역사적전망을 사용한 재현 시나리오이지 최신 확정임금 추계가 아니다.
최저임금−시설평균시급의 양수차액×대상수×시간×개월에 승인한30/50/100%지원률을 적용한다. 원문 ‘일부지원’을100%한값으로 자동확정하지 않는다.
미래정답 대상수나 총액을 입력하지 않고 과거실적·공식기준·공개전망으로 계산했다. 근거9개·방법1개 추가로 DB변수783개·방법70개다.
