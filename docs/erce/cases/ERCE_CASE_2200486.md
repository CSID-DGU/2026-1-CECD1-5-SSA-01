# ERCE 개발 검증: 2200486 아동복지법 일부개정법률안

- 발의일: 2024-06-14 / 공식 추계 회답일: 2024-06-18.
- development_manifest.jsonl에 포함된 개발용 의안. 별도 검증셋에서 가져오지 않음.
- 원문을 먼저 읽고 AI 역할을 수동 수행해 `analyze_erce_pdf(ai_draft=...)`를 실행한 뒤 정답을 열람함. API 호출 없음.

## 정답 확인 전 실행

- 제42조제1항: 18세 미만 모든 아동의 자산형성 계좌에 매월 정부 적립. `transfer_recipient` 경로 선택.
- 원문 3쪽 인용 검증 성공. 연결 산식: 대상자 수 × 참여율 × 1인당 지급액 × 연간 지급횟수.
- 월 10만원은 법률상 상한으로, 확정 지급액으로 입력하지 않음. 월 지급은 연 12개월 적용의 근거가 될 수 있으나 첫해 적용 기간·시행연도는 별도 가정이 필요함.
- 발의일 컷오프, 자기 의안 제외 조건으로 기존 로컬 DB 후보 확인. 전국 주민등록 인구만 확인됐으며 18세 미만 대상과 맞지 않아 선택하지 않음. 적용 가능한 아동 인구·지급액 근거를 확보하지 못함.
- 실제 엔진 반환: `needs_input`, 필수 변수 2개 중 2개 부족 (`recipient_count`, `benefit_per_recipient`). 금액 미산출. 지급횟수는 엔진상 선택 변수지만 이 사례에서는 12개월 설정 없이는 단위가 맞지 않음.
- 이 실행은 제1항 일반 적립 항목만 대상으로 함. 제2항 취약계층 추가 적립은 별도 검토 필요하며 전체 의안 처리 완료로 보지 않음.
- 원문만 보고 현행 지원비 차감을 검토 대상으로 남겼으나, 원문에서 차감 여부는 확정하지 않음.

## 정답 확인 후 비교

- 공식 산식: 18세 미만 아동 수 × 월 10만원 × 12개월.
- 추계기간: 2026~2030. 대상자: 6,358 / 6,136 / 5,931 / 5,700 / 5,486천명 (통계청 2023.12 장래인구추계 중위시나리오).
- 공식 금액: 연도별 7.6 / 7.4 / 7.1 / 6.8 / 6.6조원, 5년 표시 합계 35.5조원.
- 월 10만원을 최대 지급 시나리오로 가정함. 법안 확정액 또는 일반적인 아동지원 단가로 간주하면 안 됨.
- 제2항 추가 지원은 기존 아동발달지원계좌 사업으로 충당해 순증 없음으로 가정. 전 아동 일반 적립은 새로운 지급이므로 기존 사업비를 일괄 차감하지 않음.
- 조직·인력 확대도 없는 것으로 가정함.

## 판정 및 남은 작업

- 제1항 일반 적립의 산식 형태는 공식 산식과 일치. 다만 일반 경로 연결만 됐으며 지급기간·상한 적용 시나리오·대상자 전망을 채우지 못해 금액 오차율은 산출 불가.
- 발의일 당시 공개된 연령별 인구 전망을 근거 DB에 확보하는 작업, 상한을 시나리오로 선택하는 절차, 제2항 기존 사업 충당 여부 검토가 필요.
- 본 기록 작성 시 산식·단가 DB 보강 또는 정답값 재계산은 수행하지 않음. 정답 확인 후 재현과 최초 검증 결과는 구분해야 함.

## 보강 후 재계산 (2026-10-02)

- 전용 경로 `이전지출 → 개인지원 → 아동자산형성월적립` (`transfer_child_asset_monthly`) 연결.
- 산식은 `연도별 18세 미만 아동 수 × 월 적립액 × 연간 지원개월 수`. 지원개월 수를 필수로 바꿔 월 금액이 연 1회로 계산되는 실수를 방지함. 월 단위 금액 및 지원개월 0~12 검증 포함.
- 로컬 변수 DB에 4건 추가: 2026~2030년 전국 18세 미만 인구 전망, 월 10만원 최대 적립 시나리오, 연 12개월 지원 가정, 직접 계산에 사용할 수 없는 법률상 상한.
- 인구 전망은 단가가 아닌 대상자 통계이며 연령·지역·전망 버전·적용연도를 기록함. 원 통계 재확인 전까지 공개일은 정답 회답일 2024-06-18로 보수적으로 제한.
- 최대 지급액은 확정 공식 단가로 저장하지 않음. 선택 시 `benefit_scenario=child_asset_monthly_maximum_100000` 필요. 다른 의안에 재사용하려면 대상·조건이 일치한다는 적용 사유도 필요.
- 정답 확인 후 개발 재계산에서 필수 변수 3/3 충족: 연간 7.6296 / 7.3632 / 7.1172 / 6.8400 / 6.5832조원, 합계 **35.5332조원**.
- 정답 표시 합계 35.5조원 대비 **0.094%** 차이. 입력 인구와 정답 총액이 각각 반올림돼 있으며 정답의 원 단위 정확 금액 대비 오차는 아님. 최초 정답 제외 성능으로 보고하지 않음.
- 제2항 추가 적립과 행정 인력은 정답의 기존 사업 충당·순증 없음 가정을 확인함. 이 판단을 다른 의안에서 자동으로 재사용하는 규칙은 만들지 않았음.
- 검증: 월별 지급의 필수 입력·단위·개월 범위, 자기 정답 차단, 미래 근거 차단, 시나리오 확인 및 다른 의안의 적용 사유 요구 등 관련 단위 테스트 23건 통과.
