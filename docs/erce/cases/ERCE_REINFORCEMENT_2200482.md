# 2200482 보강 — 외부 사업계획 기반의 5개 비용 구성

2026-10-06. 정답 확인 후 개발 보강이며 최초 실행 기록은 변경하지 않았다.

## 반영

- 기존 연간금액 계산 엔진에 제출계획 하위 산식을 연결했다. 새 별도 계산엔진은 만들지 않았다.
- 단가/변수 DB에 10개 근거 행, 방법 DB에 1개 재사용 방법을 추가했다. 모두 비용추계서에 인용된 과거 계획/가정이며 최신 공식값이나 독립 확보된 사업계획 원본이 아니다.
- 기관수·기관당 정원·중앙 정원을 분리해 신규 법안의 명시값이 선례 후보보다 우선하도록 했다. 39개/81명을 모든 지원체계의 고정값으로 쓰지 않는다.
- 운영비: (중앙기관+지역기관)×연간 기관단가.
- 사업비: 지역기관×기관당 지킴이×월활동비×활동개월. 활동개월은 미확정이라 정상 사용 시 입력 요청한다.
- 인건비: (중앙정원+지역기관×기관당 정원)×연도별 1인 총보수. 표의 2025~2029 급여단가는 해당 기간만 사용 가능하다. 퇴직적립/기관보험료가 포함되어 있어 공무원보수표나 기관부담률을 다시 곱하지 않는다.
- 연구/전산 비용은 각 첫해만 반영한다. 국비·지방비 합산이며 50% 보조율로 합산액을 줄이지 않는다.
- 검색 방법에 ‘원문 밖 부처 사업계획 확인 → 5개 항목 분리 → 규모 확인 → 활동기간 확인’을 남겼다. 정의 조문이나 노력규정이라는 이유만으로 비용 0/미추계를 확정하지 않는다.

## 실제 재실행

정답표의 미해결 사업비 단위는 **본 의안 개발용 표 재현 모드에서만** 표의 단가를 1회 곱했다. 일반/웹/다른 의안에서는 이 우회가 금지된다.

5개 비용항목 모두 계산. 연도별 천원:
5,345,522 / 5,087,538 / 5,182,389 / 5,280,237 / 5,381,082.

합계 **26,276,768천원 = 262.76768억원**.
정답 **26,277,000천원 = 262.77억원**.
차이 **232천원, 0.000883%**. 항목별 표시단가의 반올림 차이가 남으며 결과를 정답총액에 맞춰 역산하지 않았다.
