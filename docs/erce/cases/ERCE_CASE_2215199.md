# ERCE 사례2215199: 국회 미래전략특별위원회 신설

## 실행 범위

2026-09-27 현재 자료 기준 ERCE 실행. 법안 원문을 먼저 보고 대상 비용추계서는 금액 고정 후 열었다.
과거 별도 엔진의 홀드아웃 자료에도 이 의안이 존재하므로 프로젝트 전체에서 완전히 미사용된 신규 검증셋이라고 주장하지 않는다.
이번 입력에서는 자기 정답을 제외한다. 다른 선례는2026년까지 공개된 자료를 사용하며2025년 말 최초 제출 시점 테스트로 소급 주장하지 않는다.

## 정답 확인 전 AI 판단

법안은 국회의원15명으로 구성된 상설 미래전략특별위원회 설치 및 국회미래연구원의 연구 협력을 규정한다.
의원15명을 민간위원15명으로 보고 회의 참석수당을 곱하는 경로는 **대상 신분·업무가 달라 제외**한다.
국회미래연구원은 기존 기관이므로 별도 신규 연구기관 인건비를 중복해서 추가하지 않는다.
추가 연구 업무량은 법안에 없어 별도 금액을 확정하지 않는다.

국회 위원회 지원공무원과 운영비를 다음처럼 분리해 산식을 선택한다.

- 보수: 순증 지원인력×같은 국회 지원직군의 연도별 평균보수.
- 기관부담금: 계산한 보수×연도별 기관부담률.
- 기본경비: 계산한 보수×국회 기본경비 비율.
- 자산: 순증인원×신설 첫해 자산단가(첫해1회만).
- 운영지원 사업비: 기준 연간예산×물가 상승계수.

## 단가·규모 후보의 채택 및 제외

1. 의안2214994 국제개발협력특별위원회: 의원18명, 소규모 상임위11·9명 지원공무원 평균10명,
   운영사업비1.56억원. 대상15명 위원회와 같은 국회 상설 심의조직이라 비교 가정으로 채택한다.
   의원15/18 비율로 지원직원을 임의 비례축소하지 않는다. 지원인력10명은 법안 명시 정원이 아니다.
2. 같은 문서의 첫해 지원직원 보수384백만원은7개월 반영액이며, 이 숫자를 완전한1년 보수로 복사하지 않는다.
   표시된 후속연도와 연환산 차이가 있어 신규 급여 단가로 채택하지 않았다.
3. 의안2212534 헌법개정특별위원회: 지원직원11명의2026~2030년 완전연도 보수총액을11명으로 나누어
   같은 국회 지원직군의 평균보수로 사용한다. 대상10명과 직급구성이 조금 다르므로 근사치임을 명시한다.
   50명 의원·500명 국민참여회의·전문가 지원을 포함한 전체 사업규모나 총액은 복사하지 않는다.
4. 기관부담률13.067~13.379%, 기본경비8.2%, 자산498만원/인, 사업비 연2% 상승은
   관련 선례에서 분리해 인용한다. 선례에 인용된 값을 공식 원문 독립 검증값으로 승격하지 않는다.
5. 2026년 국회 각목명세서 공개 원문을 공식 도메인에서 검색했으나 이번 검색으로 해당 직급 보수표를 확보하지 못했다.
   따라서 선례 평균보수를 현재 공식 보수표라고 부르지 않는다.

인력은 재배치 근거가 없다는 조건하에10명 순증 시나리오로 계산한다.
기존 인력 재배치·미래연구원 지원 범위에 따라 인원은 줄어들 수 있다.
회의실·사무실은 국회 유휴공간 활용 선례 가정을 적용하며 새 건설비를 임의로 만들지 않는다.
이것이 실제로 충분한 공간이 있다는 독립 확인은 아니다.
추계기간은2026~2030년, 공포 즉시 시행 기준으로 첫해 전체기간 가정이다.

## 정답 비교 및 최초 실패

대상 정답:25D6889, 회답2026-03-24. 2027~2031년 합계 **4,880,000천원(48.80억원)**.
최초 결과 대비 총액 오차율 **38.96%**. 추계기간도 최초2026~2030년에서 정답2027~2031년으로 달랐다.

비용분해(보수·기관부담금·기본경비·자산·운영사업비)와 산식 자체는 맞았다.
주요 오류는 같은 국회 위원회라는 이유로 지원인력10명 모델을 고른 AI 판단이다.
국제개발협력위원회는 법률안·예산·결산 예비심사 업무를 포함한다.
대상 미래전략위원회는 법률안 수가 적고 예결산 예비심사 업무가 포함되지 않는다.
이 차이는 원문에서도 판정할 수 있었는데 최초 선택에서 충분히 반영하지 못했다.
정답은 특별위원회 모델6명을 가정한다. 의원15명과 지원공무원6명은 다른 값이다.

또한6명 모델은 수석전문위원·전문위원의 비중이 높아 10·11명 모델의 평균보수를 그대로 쓰면
이번에는 보수가 과소추계될 수 있다. 인원수만 줄이고 단가를 유지하는 것도 정확한 보강이 아니다.

## 보강 범위

1. 인력 가정표에 `budget_settlement_pre_review`(예결산 예비심사 권한) 조건을 보존한다.
   이번 대상처럼 해당 권한이 없는 입력에10명 모델을 적용하면 DB 선택 단계에서 거부한다.
   권한 여부 자체는 AI가 원문을 읽고 판단한다. 이 플래그가 모든 법안 업무량을 충분히 표현하는 것은 아니다.
2. 제한된 정책심의형 특별위원회6명 모델과 직급구성(수석1·전문1·4~5급1·6급1·8급1·9급1)을 추가한다.
   6명은 국회 모든 위원회의 법정 고정 정원이 아니라 해당 선례의 가정이다.
3. 공개 정답에서 이 직급모델의 연도별 보수총액을 인원수6으로 나눈 단가를 저장한다.
   해당 직급구성을 명시하지 않거나 다른 구성으로 선택하면 거부한다.
   이 급여 관찰값은 공식 급여 예산표 원본을 독립 검증한 값이 아니다.
   공식 원문을 웹 검색하고 법령 페이지 열기도 시도했지만 이번 작업에서는 직제 별표·급여표를 확보하지 못했다.
4. 2027년 적용 자산단가508만원/인, 기관부담 전망표2027~2031년을 기록한다.
   기관부담 각주 마지막 연도가2030으로 중복 표기되어 있으므로, 본문 추계기간에 따른2031 해석을 원문 오류와 함께 보존한다.
5. 새 대상의 신설연도·기간은 별도 판단한다. 전 사례의 일부 기간·과거 시작연도를 자동 전용하지 않는다.
6. 지원사업비는 기존 유사위원회 평균1.56억원과 연2% 가정을 유지한다.
   정답의1.55억원으로 덮어쓰지 않는다. 새로운 공식 예산 원본이 확인되면 연도별 버전을 별도로 추가한다.

값을 '공식 표준'이라고 승격시키지 않고, 자기 정답 배제/연도/업무 권한/직급구성 조건을 적용한다.
검토한 자기 문서의 값은 `development_review`에서만 이번 재계산에 허용한다.

국회미래연구원의 추가 업무는 정답에서도 별도 업무량·증원 규모를 추정하지 못해 미추계했다.
이 실행을 연구원 추가업무까지 모두 해결한 전체 추계라고 부르지 않는다.
