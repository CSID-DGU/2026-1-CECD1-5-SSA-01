# ERCE 실행 — 2200490 6·25참전 소년소녀병 보상에 관한 법률안

2026-10-02 실행. 개발용 목록에 있고 교육지원·보상 신규 20건 및 기존 평가셋에서 제외된 의안. AI 역할은 개발 에이전트가 수행, GPT API 호출 없음.

## 정답 확인 전 실제 실행

- 원문 10쪽 확인 후 `analyze_erce_pdf(ai_draft=...)` 실행. 제3·4·5·10조 인용 4개 모두 PDF 검증 통과.
- 제3조 → 위원회 회의수당 산식, 제4조 → 대상자 × 보상금, 제5조 → 추가 대상자 × 추가 보상금, 제10조 → 송달 산식으로 분류.
- 위원회 9인 이내는 총 정원 상한이므로 유급위원 9명으로 채우지 않음. 본인·유족 인원, 지급액, 회의·송달 횟수는 원문에 없음. 신청기간 2년을 매년 반복 지급기간으로 간주하지 않음. 제20조 기존 급여 고려도 임의 차감하지 않음.
- 네 경로 모두 연결됨(`unmappedCount=0`)이나 금액은 계산되지 않음. 필수 입력 묶음 기준 위원회 1개, 기본보상 2개, 추가보상 2개, 송달 4개 부족. 이는 사용자 질문을 9번 해야 한다는 의미가 아니며, 근거를 먼저 탐색할 대상임.
- 자기 의안 제외·발의일 2024-06-14까지 공개된 검토 DB 검색: 소년소녀병/이중징집 관련 적합 근거 각각 0건. 다른 보상과 수급자 정의가 달라 유족연금 승진 단가를 재사용하지 않음.

## 이후 정답 비교

- 회답 2024-08-02. 정답 2026~2030 합계 **72,130백만원(721억3,000만원)**.
- 정답 제3조는 회의수당만이 아니라 지원 직원 3명의 인건비(기관부담금 포함)·사업비·위원회 수당·기본경비를 포함함. 앞선 위원회 산식은 불완전하며 **전용 운영비 구성 분해 필요**.
- 제4조는 본인/유족별 신청률 × 인용률로 수급자를 추정하고 1인 1,000만원을 일시 지급. 기존 대상자 × 단가 산식은 금액 곱셈에 재사용 가능하나 **대상 인원 산출·연도별 지급 배분 가정이 부족**함.
- 제5조는 국방부 자료상 이중징집자가 없어 미추계. 앞선 추가보상 후보 탐지는 가능하지만 추계 결정은 정답과 다름. 근거 없는 0명 또는 지급액을 생성하지 않았음.
- 제10조 송달은 정답에 별도 비용 항목으로 계상되지 않음. 위원회 사업·운영비 포함 여부를 검토해야 하며 중복 합산하지 않음.
- 정답은 위원회 운영비 270·270·270·135·135백만원, 보상금 23,690·22,680·22,680·1,000·1,000백만원. 대상 본인 2,635/유족 24,414명, 신청률 61.0%/26.6%, 인용률 87.6%, 지급 인원 총 7,105명으로 가정함.
- **이번 실행 금액 없음 → 금액 오차율 산출 불가.** 경로가 연결됐다는 사실을 산식·변수가 모두 맞았다는 의미로 보고하지 않음. 이번 의안은 실행·진단까지만 완료, 정답 변수 적재 및 운영비 보강은 다음 작업.
