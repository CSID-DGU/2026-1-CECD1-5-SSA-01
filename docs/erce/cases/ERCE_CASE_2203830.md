# ERCE 사례 2203830: 공무직위원회

## 정답 확인 전

- 운영비: `물건비/위원회/과거운영실적기반`
- 산식: 2020~2022년 공무직위원회 운영비 평균 10.4억원에 연도별 물가상승률 적용
- 2025~2029년: `[1,124,266, 1,145,627, 1,168,539, 1,191,910, 1,215,748]`천원
- 합계: **5,846,090천원**

기획단 2개 과의 정원·직급, 발전협의회 구성·횟수는 적합한 근거가 없어 임의로 산정하지 않는다.

## 정답 비교

정답은 **5,868,000천원**, 정답 전 결과는 **5,846,090천원**으로 오차율은 약 **0.37%**다.
산식·운영실적 선택은 맞았고, 차이는 2024.11과 2025.11 물가전망치 버전 차이다.
정답도 기존 기획단 규모가 유사하다고 보아 인건비를 별도로 가산하지 않았다.
