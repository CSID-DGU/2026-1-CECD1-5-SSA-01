# 2216665 보호대상아동 보험지원 및 실태조사 대상추가

자기DB근거0건·기존실행기록없음·검증셋미포함을 확인했다. 원문을읽고 정답미열람상태에서 공식2025복지안내책자 위탁아동 연보험료68500원을 확보해 실제웹 계산을 실행한 뒤첫결과를저장했다.

처음에는원문2024시설9904명+공동생활2578명을합친12482명을5년유지하는참고가정으로 계산했다. 기존보험을지원받는가정위탁7703명은제외했다.2027~2031단가동결·연1회로보험참고액42.75085억원을얻었다. 실태조사대상추가는단가부족으로needs_input이었다.

정답26C0846(2026-04-15)은 상해보험료만 일부추계하여35.93억원이다. 같은단가68500원·동결·기간을쓰지만2020~2024보호아동의아동인구대비평균비중을산출하고 장래인구에적용한다. 지급인원은11198/10838/10506/10128/9775명이며백만원표시는767/742/720/694/670이다.

상해보험료부분의정답표시합계대비참고금액오차는18.98%가량이다. 전체금액은미산출이므로이비율을전체의안오차로주장하지않는다. 단가와곱셈산식은맞았지만인원전망을고정한것이주요차이다.

정답은조사표본크기·선정방법·조사항목이미확정이므로조사대상확대비를미추계한다. 기존조사비는2018년400백만원,2023년600백만원,2026년618백만원이나그총예산을추가대상비로복사하지않는다. 최초needs_input을동일한근거있는미추계판정이라고보면안된다.

정답은상해보험료만계산했고배상책임보험료의별도금액은제시하지않았다. 최초공식상해보험료단가준용을배상책임보험의독립가격검증으로주장하지않는다.

보강시2020~2024비중원자료·모집단·표시0.17%의정밀도및아동인구기준을확인해야한다. 정답미래인원을새원관측값으로저장해서는안된다. 이번은실행요청이며보강은아직하지않았다.
