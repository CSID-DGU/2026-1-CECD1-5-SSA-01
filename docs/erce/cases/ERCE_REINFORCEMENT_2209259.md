# 2209259 사회보장위원회 확대 보강

2026-10-10. **공식 추계범위 재현 완료.** 최초 실행의 금액 미산출 기록은 유지했다.

## 유지와 추가

기존 중앙정책 신설위원회의 연4회·대면20만원·서면10만원 근거는 수정하지 않았다. 사회보장위원회 기존 본회의 확대를 별도 하위 프로필 `social_security_committee_expansion`로 연결했다.
원문의 기존 상한30명·개정 상한35명을 받아 차이를 계산하고, 승인된 추가 당연직1명 참고 가정을 차감하여 유급 순증4명을 산출한다. 전체35명 운영비나 최대 증가5명 전원 유급으로 계산하지 않는다.
해당 위원회의2023·2024 본회의 각3회 실적에 근거한 연3회, 대면20만원/서면10만원을 별도 DB 행으로 저장했다. 단가 금액 자체는 기존 후보와 같지만 위원회·회의형태·출처를 구분한다. 구성·횟수·지급 범위 설명과 명시적 승인 없이는 계산하지 않는다.
새 변수 근거4개 및 방법1개를 추가하여 DB는 변수723개·방법54개다. 공식 현재 고정요율로 표시하지 않고 역사적 실적과 구성 참고 가정임을 유지한다.

## 회귀 결과

**(35−30−1명) ×3회 ×20만원 ×5년 =1,200만원**.
연240만원, 연도별5/5개·총액 모두 정답과 정확히 일치하며 오차 **0%**다. 계산 값의 반올림 차이도 없다.
서면으로 선택하면 연120만원, 개정상한36명으로 바꾸면 연300만원이 계산된다. 무급 순증이 전체 순증보다 크거나 역할이 다르면 거부하고, 정원 입력이 없으면 부족 변수를 반환한다.
개발 회귀는 실제 의안으로 실행했다. 웹은 자기 선례 제외를 유지한 별도 유사 의안 식별자로 검사했으며 양쪽 금액이 일치했다.
이는 정답 확인 후 보강 회귀이지 최초 실행이나 독립 새 의안 성과가 아니다. 분과회의 등의 별도 추가효과와 공식 추계범위 완료 여부를 혼동하지 않는다.
