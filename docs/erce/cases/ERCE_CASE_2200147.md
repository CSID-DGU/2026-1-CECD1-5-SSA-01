# ERCE 실행 기록 — 2200147 아동수당법

실행일: 2026-10-02. 개발 AI 역할은 대화 에이전트가 수행했으며 GPT API는 호출하지 않음. 기존 사례 기록 및 별도 검증셋에 포함되지 않은 개발용 의안임.

## 정답 열람 전 판단·실행

- 원문 `backend/generated/assembly_22_pdfs/by_bill/2200147/bill_text.pdf` 전체 확인. 제4조에서 대상 연령을 8세 미만→18세 미만, 월 지급액을 10만원→20만원으로 변경. 부칙상 2025-01-01 시행.
- 사회보장급여 / 이전지출. 기존 0~7세 수급자 인상분과 신규 8~17세 지원분을 구분함. 제5·7·10조의 대상 연령 변경은 동일 급여 사업의 절차 변경으로 별도 급여를 중복 계상하지 않음.
- 기존 집단: `transfer_recipient_delta`, 기존 수급자 수 × (월 20만원 − 월 10만원) × 12회.
- 신규 집단: `transfer_recipient`, 신규 대상 인구 × 지급률 × 월 20만원 × 12회.
- 원문의 만원을 원으로, 매월을 연 12회로 환산한 수동 AI 입력을 `calculate_erce_web_item`에 전달. 두 항목 모두 `needs_input`, 부족 필수변수는 각각 `recipient_count`.
- 현재 로컬 단가 DB에서 자기 의안 제외 및 2025~2029년 일치 조건으로 검색한 검토 완료 `recipient_count` 후보는 0건. 현재 데이터 재사용 관점으로 공개시점 상한은 실행일을 사용했으며, 발의 당시 재현을 주장하지 않음.
- 기존 2200486의 18세 미만 인구는 2026~2030년 자료이고 8세 미만 구분도 없어 선택하지 않음. 기존 구조화 변수 JSONL에서도 아동수당·8세 미만 등의 관련 문구를 검색했으나 적절한 두 집단 인구 시계열 숫자를 확보하지 못함.
- 인구를 임의 생성하지 않았으므로 최초 실행의 금액 결과는 없음. 금액 오차율은 계산 불가.

## 이후 정답 비교

- 정답 `cost_estimate.pdf`, 회답일 2024-06-13, 추계번호 24C0335.
- 정답 산식: 18세 미만 인구 × 월 20만원 × 12개월 × 지급률 − 8세 미만 인구 × 월 10만원 × 12개월 × 지급률. 최초의 두 집단 분해와 대수적으로 대응함.
- 정답은 2024년 지급률 **97.2%**를 두 집단 모두에 적용함. 최초 실행에서는 이 비율을 확보하지 못했음. `transfer_recipient`는 지급률 입력을 지원하지만 `transfer_recipient_delta`는 해당 변수를 지원하지 않으므로, 최초 선택을 완전히 일치하는 산식이라고 평가할 수 없음. 기존 집단은 실제 수급자 수를 쓰거나 지급률 반영이 가능한 별도 계산 구조가 필요함.
- 정답 인구(천명): 18세 미만 `[6625, 6358, 6136, 5931, 5700]`, 8세 미만 `[2177, 2046, 1953, 1898, 1872]`. 통계청 장래인구추계(2023.12.) 중위 시나리오. 표의 인구는 반올림 표시값임.
- 정답은 총 추가소요 **60조 1,356억원**, 국고보조율 **75.55%**로 국비·지방비를 나눔.
- 따라서 금액 계산에 필요한 미확보 자료는 두 연령 집단의 연도별 인구와 지급률임. 재원별 분리까지 하려면 국고보조율도 필요함. 엔진의 필수변수 부족 표시 2건만으로 모든 전제가 확보됐다고 판단하면 안 됨.
- 최초 실행에서는 실행·비교만 수행했으며, 아래는 이후 요청에 따른 보강 기록임.

## 보강 및 재계산 (2026-10-02)

- 기존 인상분 산식에 선택 입력 `participation_rate`를 연결함. 실제 수급자 수 입력 시 기본값 1을 유지하고, 대상 인구 입력 시 별도 지급률을 선택하도록 함. AI가 인구와 실제 수급자 수를 구별해야 하며 자동 식별 기능을 추가한 것은 아님.
- 로컬 DB에 5행 추가: 2025~2029년 0~7세·0~17세 인구, 두 인구의 차로 산출한 8~17세 인구, 지급률 97.2%, 국고보조율 75.55%.
- 모든 행은 출처·자료연도·연령·지역·적용기간·재사용 제한을 기록함. 자기 정답 제외와 공개시점 제한 유지. 다른 의안에서는 적용 근거를 남겨야 선택 가능함.
- 인구는 추계서에 표시된 천명 단위 반올림 값을 명으로 환산함. 공식 원 통계의 1명 단위 값을 직접 검증하거나 최신 인구를 새로 내려받은 것은 아님.
- 웹 확인: 공식 [장래인구추계 2022~2072년, 2023-12-14 발표](https://www.kostat.go.kr/board.es?act=view&bid=207&list_no=428476&mid=a10301020100)에서 통계 버전의 출처를 확인함. 검색만으로 최신 세별 통계 버전을 확정하지 않았으므로 최신값 표시는 하지 않음. 2024년 지급률·보조율 또한 선례의 동결 가정으로 저장했으며 최신 실적값으로 분류하지 않음.
- 저장된 인구·지급률을 선택하고 법안의 월 지급액·지급주기를 사용해 기존 집단과 신규 집단을 재계산함. 5년 합계 **60조 1,325억 8,560만원**, 정답 **60조 1,356억원** 대비 **약 0.0050% 과소**. 표의 인구 반올림 정밀도 제한이 있으며 원자료 없이 잔차 전체 원인을 확정하지 않음.
- 정답을 본 뒤 보강한 재계산이므로 미확인 법안에 대한 일반화 성능으로 해석하지 않음. 관련 테스트 **25개 통과**. 국고보조율은 DB에 저장했으나 이번 재계산은 국비·지방비 분리가 아닌 총 추가재정소요 비교임.
