# ERCE 사례 2200037: 전국민 민생회복지원금

## 정답 확인 전

- 라우팅: `이전지출/개인지원/일반급여`
- 산식: 지급대상자 수 × 1인당 지원금 × 1회
- 인구: 2024년 5월 전국 주민등록인구 51,277,347명
- 단가: 법안 명시 25만~35만원

정답 확인 전 범위는 **12,819,336,750천원~17,947,071,450천원**이다.
소득별 지급액 분포가 없으므로 중간값을 임의로 고르지 않는다.

## 정답 비교

정답도 같은 인구와 25만·35만원 시나리오를 사용했다.
백만원 단위 표시의 단수 차이를 제외하면 **오차 0%**다.
지역사랑상품권 발행비는 지자체별 규모를 예측할 수 없어 정답과 동일하게 미추계했다.
