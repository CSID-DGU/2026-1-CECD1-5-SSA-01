# ERCE 첫 실행 — 2200601 학교급식법 개정안

2026-10-03. 교육지원 중 영양교사 증원 사례. 개발 목록 포함, 교육지원·보상 분리 평가셋 제외를 확인했다. 개발 에이전트가 AI 역할을 수행했으며 GPT API 호출은 없다. 기존 정책 분류 목록에서 같은 법률명을 선택했으므로 무작위 격리 평가가 아니다.

## 정답을 열기 전 실행

- 원문6쪽을 읽었다. 일정 규모 이상 학교에 영양교사를2명 이상 배치하는 제7조제1항 후단의 신설만 신규 의무로 판단했다. 유치원 기준의 항 이동은 기존 의무이므로 중복 비용으로 만들지 않았다.
- `analyze_erce_pdf(ai_draft=...)`를 실제 실행했다. 보수는 `personnel_average`, 기관부담금은 `personnel_employer_contribution`으로 연결했다. 조문 인용2/2 확인, 미등록 경로0개였다.
- 학교당2명 이상은 총 배치 하한이지 전국 순증 인원이 아니다. 대상 규모 기준이 대통령령에 위임되어 있으므로 전국 인원수나 추가1명 배치 가정을 원문 확정값으로 추출하지 않았다. 시행일은 공포 후1년이라 확정 시작연도도 추출하지 않았다.
- 현재 로컬 근거 DB에서 자기 정답을 제외하고 검색했다. 영양교사·교사 관련 근거0개. 학교급식 관련3개는 학생 식품비·운영비와 공공분담률이므로 교사 보수에 사용하지 않았다. 국회 지원 인원의 순증 정원과 평균 보수도 업무·신분이 달라 채택하지 않았다.
- 공식 봉급표516행은2026년 일반직·공안직이고 교원 표가 아니다. 월 기본봉급을 교원의 수당 포함 연간 총보수로 대체하지 않았다.
- 보수 필수 입력2개(순증 인원, 교원1인당 연간 보수), 기관부담금 필수 입력2개(보수총액, 기관부담률)가 모두 부족했다. 뒤 항목의 보수총액은 앞 항목이 계산되면 전달할 파생값이므로 독립 근거가 필요한 값은 인원·보수·부담률3개다. 기관 증원용 관할인구 비례 후보도 교사 배치에 적합하지 않아 선택하지 않았다.
- 금액은 생성하지 않았다. 정답 열람 전 `docs/erce/first_runs/ERCE_FIRST_RUN_2200601.json`에 입력·검색·거절 근거·부족 변수를 저장했다. 최초 결과는 이후 변경하지 않는다. 현재 개발 DB를 이용한 시험이며 발의 당시 자료만으로 제한한 시험이 아니다.

## 정답 열람 후 비교

- 정답24C1048, 회답2024-07-11. 시나리오1은 초등학교1,500명 초과 및 중·고등학교1,200명 초과, 시나리오2는 초등학교1,000명 초과 및 중·고등학교1,200명 초과다. 대상학교마다1명을 추가한다고 가정했다. 원문에서 확정할 수 없는 기준을 교육통계 구간으로 구성한 대안 시나리오다.
- 국·공립 순증 인원은156명/618명, 사립은8명/9명이다. 교육통계2023년 자료를 사용하고5년간 인원을 동결했다. 두 시나리오를 합산하지 않는다.
- 국·공립 비용은①봉급·수당 ②기관부담금 ③기본경비 ④첫해 자산취득비, 사립은⑤사학연금 국가부담금이다. 이5개 계산 구성요소 기준으로 첫 실행은①②만 선택하여 **2/5개 포착**, ③④⑤는 누락했다. 다만 각 구성요소에 대응하는 일반 계산 산식 자체는 기존 ERCE에 등록되어 있어, 산식 라이브러리가 없는 문제와 AI가 항목을 선택하지 않은 문제를 구분해야 한다.
- 신규 교원2급·8호봉 임용, 매년1호봉 상승,2026-01-01 근무 시작을 가정했다. 일반직 연간 평균보수가 아니라 교원 봉급·수당·호봉 진행이 필요한 사례다. 기본경비는 인건비(봉급·수당+기관부담금)의6.54%, 자산취득은 첫해1회이며 사립학교에 국·공립의 전체 인건비를 그대로 부담시키지 않는다.
- 사립학교의 재정결함보조 증가분은 세입·세출과 지역별 기준을 확인할 수 없어 정답도 산정하지 않았다. 정답 총액은 완전한 전체 비용이 아닌 일부 범위의 추계다.
- 정답2026~2030 총액은 시나리오1 **36,796백만원(367억9,600만원)**, 시나리오2 **145,570백만원(1,455억7,000만원)**이다. 첫 실행은 금액 미계산이므로 오차율 산출 불가다. 정답 값을 채워 최초 성능으로 보고하지 않는다.

## 향후 보강 시 주의

- 학교 규모별 추가배치 시나리오와 교원 급여 구조를 별도로 저장해야 한다. 대상학교 수는 모집단·연도·공사립·초중고·규모 기준을 묶어서 관리하고 단순 영양교사 전체 인원으로 전용하지 않는다.
- 기본경비의 기준이 봉급·수당이 아니라 기관부담금을 포함한 인건비인지 확인하고, 사립 연금 국가부담과 다른 기관부담률을 구별한다.
- 정답 본문은 사립 연금에 봉급·수당을 적용한다고 설명하지만 표6의1인당 보수47/44/46/48/50백만원은 표3의 기본경비·첫해 자산을 포함한 총단가와 같고, 봉급·수당35/37/38/40/41백만원과 다르다. 사립 표 금액도 전자의 단가에3.706%를 적용한 값에 가깝다. 이 불일치를 일반 규칙으로 확정하거나 정답을 무조건 잘못됐다고 판정하지 말고, 표 재현과 본문상 산식을 별도 검토한다.
- 최초 실행 턴은 비교·기록까지만 수행했다. 이후 사용자의 보강 요청에 따라 아래 변경을 추가했다.

## 재사용 보강 및 정답 확인 후 재검산

- 기존 산식5개를 연결하고 영양교사 증원의 비용 검토 목록을 추가했다. 원문의 `2명 이상 영양교사` 증원 조문과 보수 경로가 선택되면, 누락된 기본경비·첫해 집기·사립 연금 국가부담을 `conditional_review` 후보로 제시한다. 이는 비용 확정이나 자동 가산이 아니며 AI/담당자의 적용 범위 확인이 필요하다. API 분석 지시문에도 국공립·사립 분리 및 비용 구성 검토를 추가했으나 실제 API 성능은 이 턴에서 평가하지 않았다.
- 기존 첫 실행 입력을 그대로 다시 분석했을 때 실제 PDF 인용2/2 통과, 계산 항목은 여전히2개이며 누락3개는 검토 후보로 나온다. 정답을 확인한 개발 에이전트가 범위를 선택한 별도 초안은5개 항목 모두 연결, 인용5/5 통과했다. 최초 자동 선택이5/5였다고 보고하지 않는다.
- 로컬 DB에 근거10행을 추가했다. 국공립·사립×시나리오별 인원4행은 해당 의안 전용이며, 보수·기관부담액·기본경비율·초기집기단가·1년 적용기간·사립연금비율6행은 조건부 재사용이다. 교원 자격·기산호봉·호봉 상승 및 연도, 공사립, 비용 구성요소가 맞지 않으면 선택을 거부한다. 단순 유사 주제만으로 인원이나 일반직 평균보수를 가져오지 않는다.
- 봉급·수당35/37/38/40/41백만원과 기관부담금5/5/5/5/6백만원은 정답 표3의 반올림된 인당 경비다. 기관부담률이 정확히 공개되지 않아 두 수치를 나눠 비율을 만들지 않고, 후자는 인원×기관부담금 단가 경로로 계산한다. 반올림된 시계열을 미래 최신 호봉표로 간주하거나 또 임금 인상률을 곱하지 않는다.
- 기본경비6.54%는 봉급·수당과 기관부담금의 합에 적용한다. 초기 자산5백만원/명은 첫해에만 적용한다. 사립 연금3.706%는 본문상 동일 봉급·수당 기준으로 계산한다. 사립의 전체 인건비나 기본경비·집기 금액을 국가부담 대상으로 자동 확대하지 않는다. 원 법령을 이번 턴에 직접 확인한 최신 공식 비율이 아니라 추계서가 인용한 과거 기준이다.

- `docs/erce/cases/ERCE_REGRESSION_2200601.json`에 검토 후보·별도 개발 초안·5개 항목별 금액 및 비교 결과를 저장했다. 최초 실행 파일은 유지했다. 새 의안에서 단가만 재사용하고 인원은 전용하지 않는 동작, 적용 범위·연도·자기 정답 제외, 첫해 집기 적용, 검토 후보만 제시하는 동작을 테스트했다. 전체 로컬 unittest100개 통과. 합성 재사용 테스트를 새로운 실제 의안의 정확도로 대체하지 않는다.
