# 2208052 지급기간 연장 보강

2026-10-06. 사후보강. 첫실행8.3/12개월의조건부후보와그오차기록은변경하지않는다.

## 유지와 변경

- 맞았던인정인원·IAP·전년도생계최저액·과거추세·현행월50만원의가격인상부분을 그대로 썼다.
- 추가평균지급개월 = 기존실지급평균 / 기존법정상한 × (개정상한−기존상한).
- 이번은5.2 / 6 × (12−6) = 추가5.2개월. 개정후유효평균은10.4개월이며12개월전원수령이나서비스평균8.3개월을복사하지않는다.
- 기존 transfer_recipient 엔진에추가개월×개정단가×실수급자를 연결했다. 단가인상분은기존5.2개월로별도계산해합산하므로단가/기간증가의중복이없다.
- 기존고용실적4개를새경로용별칭으로연결했다. 숫자는추가생성하지않고원출처/확보일을유지한다. 법정6/12개월은대상원문에서받는다.
- 수령행태비례유지는정답의명시적추계가정이다. 다른가정/원문/관측값이주어지면확인된추가개월이우선하며,이비례식을모든수당의보편법칙으로간주하지않는다.
- 실제관측자료·상한이없으면입력요청. 기간이늘지않거나실평균이상한을넘는후보는차단한다.
- 방법DB에‘현금수당기간연장’하위를추가했다. 가격인상산식은변경하지않았다.

제19·20조의수당단가/현금기간변경은별도추계한다. 이를법안전체에현금기간변경이없다는조건으로잘못표현하지않도록새항목단위사유를저장했다.

추가상담인력·관리수요·기관운영근거가생기면해당미추계재사용을거부하고재추계한다. 미추계amount는None이고0원아니다. 현재후속계획부재를전수확인한주장은하지않는다.
