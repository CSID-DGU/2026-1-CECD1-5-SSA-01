## 앞단 판단과 미대상 구분

PDF AI 분석 지침에 부담금·공과금 인상 시 정부가 징수자로서 얻는 수입과 고용주·운영자로서 납부하는 지출을 각각 검토하도록 추가했다. 정부납부 지출이 있으면 수입증가만으로 법안전체를 미대상 처리하지 않으며 둘을 상계하지 않는다.
물건비→법정부담금→정부고용부담금구간차액 경로를 추가했다. 국가·지자체 공무원 및 비공무원 고용주 지출만 계산하고 민간·공공기관의 부담금전체를 정부지출에 합치지 않는다.
정답의 장려금용도 제한, 장려금환수 수입, 기금부담금 수입의 **미대상** 근거를 조문·효과별로 분리 저장했다. `out_of_scope`/미대상은 `not_estimated`/미추계와 구분하고 금액은None으로 둔다. 기금수입 미대상 적용은 정부고용주 지출을 별도 검토했다는 확인을 요구한다.
AI 분석 결과도 실제 검증결정에 따라 미대상·미추계를 구분하여 보존하도록 연결했다. 아직 이 프롬프트 보강의 GPT API 독립성능을 측정한 것은 아니다.
