# 2201907 외국영유아 부모보육료 보강 — 회귀와 재사용 경로 분리

2026-10-10. 최초 금액 미산출 기록은 유지했다. 이번 보강은 단가·모집단 계산 구조·부분추계/미추계 판단이며, 각세 외국아동 원기준자료 미확보를 정답 전망량으로 숨기지 않았다.

## 재사용 가능한 보강

실제0·1세→0세반,2세→1세반,3세→2세반 매핑과2023전체 반연령 이용률25.7%·89.2%·94.3%,2024부모보육료 월54·47.5·39.4만원,12개월·국비69.4%를 출처/시점과 DB에 저장했다.
기존KOSIS2023.12 각세인구 기준2023 및 전망2026~2030, 기존 다른 추계서에 명시된NABO2024.3 CPI를 연결했다. 원문 지원대상 확대만으로 전체인구·부모급여·기관보육료를 잘못 붙이지 않는다.
`foreign_child_parent_fee` 경로는 각세 외국아동 기준실적/해당각세 전체인구×미래각세 전체인구×반연령 이용률로 모집단을 산출한다. 가격은2024기준에2025부터 해당연도까지 물가를 한 번만 적용한다. 국비·지방비 합계를 검사한다.
가정양육수당의 미이용률 예측부족과 제3조의 선언적 이념은 별도 미추계 근거로 저장했다. 미추계는None이며0원이 아니다. 신뢰할 추가 통계가 있으면 미추계 선례를 적용할 수 없다.
DB는 변수742개·방법62개다. 역사적 가격·실적·예측은 최신값으로 표시하지 않는다.

## 공식 통계 탐색

[법무부2023 통계연보](https://www.immigration.go.kr/bbs/immigration/228/584746/artclView.do)의 공식 첨부 엑셀을 실제 다운로드해 XML을 확인했다.
2023 2장Ⅰ2의 체류외국인0~4세44,232명, 2장Ⅱ2의 등록외국인0~4세32,400명, 2장Ⅲ2의 단기체류0~4세10,918명은 확인했으나 각세0·1·2·3세를 제공하지 않는다. 등록전체 수와 합법 장기체류 대상의 범위도 자동 동일시하지 않았다.
공개 묶음통계를 임의분배하거나 대상 의안의 미래전망에서 원기준인원을 역산하지 않았다. 공식 각세 합법체류 실적은 아직 미확보다. 웹의 새 의안 재사용 경로는 `foreign_base_counts_by_age`를 요구한다.

## 자기 의안 회귀

정답표2의 전망 이용아동수를 `target_only` 행으로 별도 저장했다. 자기 의안 개발회귀만 사용할 수 있으며 새 의안 선택 및 웹의 자기선례 제외에서 거부한다. 재사용 단가가 아니다.
해당 전망량으로 금액 계산 경로를 점검하면 **3,827.7868억원**, 정답 상세표 **3,827.84억원** 대비 오차 **0.00138982%**다. 연도별 억원 요약표 **5/5개 일치**.
표에 공개된 전망량·가격 정밀도로 재계산했으므로 미세한 상세금액 차이는 유지하고 맞춤 계수를 넣지 않았다. 이를 새 의안의 독립 추계 성능으로 기록하지 않는다.
가정양육수당·보육이념 미추계 판단은 정답근거와 일치한다. 상위3~5세반의 기관선택/이용률, 추가 이용수요 및 기존 지방지원 등은 정답의 부분추계 한계로 표시한다.

**결론:** 산식·단가·분담·미추계의 재사용 구조는 보강됐다. 금액은 자기정답 전망량을 사용한 회귀로 검증했다. 정답 없이 새 의안의 모집단까지 채우려면 해당 각세 실적 원자료가 필요하다.
