# 정답 미열람 첫 실행 평가 원칙

목표는 정답 금액을 재현하는 DB가 아니라, 보강된 근거를 새로운 의안에 적용하여 합리적인 추계 초안을 만드는 것이다.

1. 개발 목록에서 미실행 의안을 고르고 분리된 평가셋은 개발 보강에 쓰지 않는다.
2. 대상 의안의 정답 PDF·추출문·정답에서 유래한 DB 행·기존 결과물을 먼저 읽지 않는다. 자기 의안 제외 및 자료 공개 시점 제한을 적용한다.
3. 원문과 이미 학습용으로 보강한 다른 의안의 근거 및 적합한 공식자료만으로 AI가 라우팅·변수 선택·미추계 사유를 결정한다. 모르면 부족 또는 가정 후보로 남기고 숫자를 생성하지 않는다.
4. 첫 실행의 선택 근거 ID, 계산 입력, 가정, 계산 결과 또는 부족 변수·보류 사유를 정답 열람 전에 별도 파일로 저장한다. 해당 결과를 이후 덮어쓰지 않는다.
5. 그다음 정답을 확인해 산식·변수·범위·금액을 비교한다. 원문만으로 불가능했던 것과 DB 선택 실패를 구분한다.
6. 오답의 재사용 가능한 근거와 산식을 보강하되, 같은 의안 재실행은 '정답 확인 후 회귀 재현'이라고 표시한다. 첫 실행 점수와 섞지 않는다.
7. 성능 평가는 다음 새 의안 또는 격리된 평가셋에서 다시 수행한다. 이미 정답을 읽은 의안은 정답 미열람 대상으로 돌아갈 수 없다.

자료 시점도 별도 표시한다. 현재 개발 DB로 과거 법안을 시험하는 것과 발의 당시 공개 자료만으로 시험하는 것은 다르다. 정답 금액만 맞았다고 추계가 정확하다고 판단하지 않으며, 항목별 산식·모집단·단위·기간·순증 범위를 함께 확인한다.
