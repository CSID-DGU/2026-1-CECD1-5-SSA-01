## 담당자식 검색 개선 (ablation, `python3 -m backend.nabo_style.eval_variants`)

담당자가 사례를 찾는 순서(같은 법률 → 같은 부처 → 조문의 구체적 대상명)를 검색에 반영. 가중치(같은 법률 0.5, 부처·항목 0.15)는 사전에 정했고 정답셋으로 튜닝하지 않음.

| 변형 | hit@1 | hit@5 | hit@20 |
|---|---:|---:|---:|
| v0 기존 | 50% | 71% | 83% |
| v1 부처 정식목록 | 52% | 71% | 84% |
| v2 + 같은 법률 가산 | 56% | 78% | 85% |
| v3 + 조문 대상명 질의 | 58% | 80% | 87% |
| v4 + 같은 부처·항목유형 가산 | 59% | 80% | 87% |

| hit@5 | 같은 법률 추계서가 정답에 있음(116) | 처음 보는 계열(138) |
|---|---:|---:|
| v0 | 81% | 62% |
| v4 | **98%** | **64%** |

- 개선은 거의 전부 형제 의안 쪽. 처음 보는 계열은 62% → 64%로 제자리. 다음 개선은 이 138건에 집중.

### 정제 후 재측정
- 정답 라벨 정제(띄어쓰기 정규화 후 지침·고시 제외, 기관명 단독·"…연구용역비" 같은 설명문 제외) → 도달 가능 239건.
- 조문 대상명 추출에서 앞 조사·어구 제거("…위하여보건복지부에인체정보보호심의위원회" → "인체정보보호심의위원회").
- v0 hit@1/5/20 = 52% / 72% / 83%, **v4 = 58% / 81% / 88%**.
- 처음 보는 계열에서 남은 실패의 상당수는 이름이 전혀 겹치지 않는 기능적 유추(인구영향평가←기술영향평가, 공급망협의회←소부장경쟁력강화위원회). 키워드 검색의 한계.
