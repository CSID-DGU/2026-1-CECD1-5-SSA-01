## 기준정보 원장 (`backend/nabo_style/ledger.py`, `data/reference_ledger.json`)

충남 사례집의 단가표와 NABO 기준정보 목록 양식을 따른 원장.

| 필드 | 의미 |
|---|---|
| indicator / name / category | 지표 키, 이름, 분류(인건비·운영비·용역비·임차료·인구·재원분담) |
| value / unit | 값과 단위(구성이 있으면 객체) |
| reference_year / as_of | 몇 년도(기준일) 값인가 |
| publisher / document / locator | 어느 기관의 어떤 문서, 고시번호·별표·쪽 |
| published_at (+confirmed) | 언제 공개됐나. 발의일 이전 값만 조회. 추정이면 표시 |
| grade | 법령·고시 / 공식 통계 / NABO 전망 / 선례·기준정보 / 가정 |
| update_cycle_years | 갱신주기. 기준시점이 주기의 1.5배 넘게 지나면 "최신값 확인 필요" 경고 |
| supersedes | 이전 버전. 값은 덮어쓰지 않고 새 행으로 추가 |
| learned_from_answer | 정답 추계서에서 처음 알게 된 사실이면 표시 |

- NABO 공통 전망치(공무원 임금상승률·기관부담금요율·1인당 자산취득비·CPI·명목임금)는 추계서 인용 시계열을 같은 `lookup`으로 시점별 조회.
- 출력 예: `주민등록인구(내국인) 2024-05-31 기준 · 행정안전부 「주민등록 인구통계(2024년 5월)」 월말 총인구 · 공개 2024-06-10(공개일 추정) · [공식 통계] · ⚠정답에서 처음 확인`
- 지원금 추계기(`support_payment.py`)는 이 원장을 단일 출처로 사용.

## 남은 일

- 원자료 대조: 공개일·수치 다수가 2차 인용(사례집·보도)이다. 고시 원문, 행안부·법무부 원자료로 `published_at_confirmed`를 채울 것.
- 국가 단위 단가 확충: 기재부 「예산안 편성 및 기금운용계획안 작성 세부지침」(위원회 수당 등), 공무원 보수규정 연봉표, 여비규정 — 연도별 행으로.
- 갱신 절차: 매년 1~2월(고시·지침 개정 시점) 새 행 추가, 3~4년 주기 기초조사 항목은 출처·산출과정 기록.

## 공개일 정정 (2026-10-15)

- NABO 추계서는 의원이 발의 전에 요청해 회답받는 경우가 많다(회답일 < 발의일 132건). 회답 시점에는 요청 의원실만 보유하므로 **공개일 = max(회답일, 발의일)**.
- `reference._texts`, `reference_miner`, `precedent_gold`, 원장 어댑터를 모두 이 기준으로 수정. 재측정 결과 검색 평가(v0 72%, v4 81% hit@5, 도달 가능 239건)는 변화 없음.
- ERCE DB는 수정하지 않음. 출처 의안 발의일보다 available_at이 이른 행 6/917(2203550, 평균 26일) — 알려진 문제로 기록.
