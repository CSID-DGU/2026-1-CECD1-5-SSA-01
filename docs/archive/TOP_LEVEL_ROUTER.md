# 비용추계 상위 라우터

## 목적

세부 비용추계기는 분야별로 순차 개발하되, 최종 결과 유형은 처음부터 하나의
공통 구조로 관리한다. 최종 분류를 LLM에 한 번에 묻지 않고 조문별 계산 결과와
검증된 근거를 규칙으로 종합한다.

```text
재정수반 없음                         -> 미대상
검증된 안보·군사기밀 사건만 존재       -> 미첨부 2호
계산 가능한 항목 존재
  모든 항목 계산                       -> 비용추계서 또는 미첨부 1호
  계산 불가능·입력 필요 항목도 존재     -> 일부추계
계산 항목 없음
  입력·근거를 보완하면 계산 가능        -> 판단 보류
  모든 항목의 기술적 추계곤란이 입증됨  -> 미첨부 3호
```

## 표준 비용 경로

1. `organization_administration`: 조직·행정운영
2. `welfare_benefit`: 복지·급여
3. `subsidy_compensation`: 보조금·보상
4. `program_service`: 사업·서비스
5. `facility_asset`: 건설·시설·자산
6. `tax_non_tax_revenue`: 조세·세외수입

현재 `organization_administration`만 `org_admin_resolver-v2`에 연결되어 있다.
나머지 경로는 상위 분류에 등록되어 있지만 세부 엔진이 연결되기 전까지
`판단 보류`로 반환한다. 엔진 미구현을 미첨부 3호로 오인하지 않는다.

## 미첨부 판정 안전장치

- 1호는 모든 비용항목이 계산된 뒤에만 금액 기준으로 판단한다.
- 일부 항목이 미계산이면 전체 금액을 알 수 없으므로 1호로 자동 분류하지 않는다.
- 2호는 AI 제안만으로 확정하지 않고 검증된 보안 근거를 요구한다.
- 3호는 핵심 누락 변수와 공식 미첨부·동일 법률 범위 근거가 모두 필요하다.
- 사람이 값을 입력하면 계산할 수 있는 경우는 3호가 아니라 `판단 보류`다.
- 계산 가능한 항목이 하나라도 있으면 전체를 3호로 보내지 않고 일부추계한다.

## 1호 금액 기준

국회 양식은 계속비용과 한시비용을 구분한다.

- 계속비용: 연평균 10억 원 미만
- 한시비용: 총 30억 원 미만

경기도 양식은 각각 연평균 1억 원, 한시 총 3억 원 기준을 사용한다. 계속비와
한시비가 섞이면 자동 1호 판정을 보수적으로 적용하고 검토자가 비용 성격을
분리할 수 있게 한다.

## 실행

```bash
python3 -m backend.scripts.run_top_level_router \
  backend/examples/top_level_router_organization.json
```

## 확장 방법

새 분야를 정복할 때는 해당 세부 엔진의 결과를 공통 `RouteOutcome`으로 변환한다.
상위 분류 규칙은 바꾸지 않는다.

- 계산 성공: `computed`
- 대상 고유값 필요: `needs_input`
- 적용 근거 필요: `needs_evidence`
- 공식 근거로 기술적 곤란 입증: `technically_unestimable`
- 검증된 보안 제한: `security_restricted`
- 추가 재정효과 없음: `no_fiscal_effect`
