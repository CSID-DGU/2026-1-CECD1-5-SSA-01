## 구조 판정

상위 분류 골격과 `계산 가능한 항목이 하나라도 있으면 일부추계`라는 우선순위는 적절하다. 다만 현재 구현은 다음 이유로 완성된 엔드투엔드 구조가 아니다.

1. `estimator_v2` 결과와 상위 라우터가 자동 연결되지 않아 이번 검증에서 수동 변환했다.
2. LLM 사건 추출이 중앙센터의 사업 수행을 `committee_operation`으로 오분류했다.
3. 안 제7조의3의 지방자치단체 삭제지원 확대를 독립 비용사건으로 명확히 보존하지 못했다.
4. 실시간 벡터 검색이 실패해 저장된 로컬 검색 결과와 구조화 선례를 사용했다. 운영용 로컬 폴백이 필요하다.
5. 현재 게이트는 `공식 선례가 진짜 문서인지`와 `그 선례가 현재 의안에 적용되는지`를 하나의 `verified`로 표현한다. 문서 진위, 비용메커니즘·누락변수 적합성, 대상 의안의 변수 확보 불가능성을 분리해야 한다.

따라서 이 사례는 **최종 결론은 정답이지만, 자동 파이프라인이 완성됐다는 증거는 아니다.**
