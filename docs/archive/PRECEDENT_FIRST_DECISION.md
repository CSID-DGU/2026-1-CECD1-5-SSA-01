# 선례 우선 비용추계 판단 구조

런타임의 판단 근거는 `비용추계의 이해와 실제`가 아니라, 날짜가 앞선 공식 비용추계서·미첨부 사유서다. 해당 문서는 개발자가 제도를 이해하기 위한 참고 자료로만 보관한다.

```text
법안 원문
  → LLM 1차: 재정수반 사건, 비용 경로, 누락 변수 추출
  → 로컬 선례 검색: 대상 의안·미래 의안 제외, 메커니즘·누락 변수 일치 사례만 제시
  → LLM 2차: 선례와 현재 조문을 비교해 추계/미첨부/미대상 판단
  → 검증 게이트: 인용한 공식 선례·누락 변수 없으면 3호 확정 불가
  → 상위 라우터: 추계서 / 일부추계 / 미첨부 1·2·3호 / 미대상 / 보류
  → 세부 산식 엔진: 준비된 조직·행정운영부터 연결
```

LLM은 현재 법안의 의미와 선례의 적용 가능성을 판단한다. 계산기와 상위 라우터는 금액 기준, 대상 의안 제외, 선례 출처 검증처럼 재현 가능해야 하는 일을 맡는다.

미첨부 3호는 아래 세 조건이 모두 충족될 때만 자동 확정한다.

1. LLM이 재정수반 요인과 추계에 필요한 누락 변수를 명시한다.
2. 로컬의 날짜상 앞선 공식 3호 선례 중 같은 재정 메커니즘 사례를 인용한다.
3. 계산 가능한 다른 비용항목이 없어야 한다. 하나라도 계산되면 일부추계로 처리한다.

`backend/estimator_v2/precedent_first.py`가 이 계약을 구현한다. 외부 벡터 DB나 방법론 RAG에 의존하지 않으며, LLM 호출자는 1차 추출과 2차 결정을 해당 데이터 구조로 전달하면 된다.
