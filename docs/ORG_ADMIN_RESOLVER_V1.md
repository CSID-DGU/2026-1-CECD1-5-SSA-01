# 조직·행정운영 Resolver v2

## 목표

AI가 조문을 해석한 뒤 제출하는 구조화 입력을 받아, 결정적인 Python
계산기가 산식을 실행한다. 근거가 없는 숫자는 생성하지 않고 필수 입력으로
반환한다.

```text
AI: 사건·조직형태·비용항목·선례 후보 구조화
Resolver: 단위·출처·적용범위 검증
Formula executor: 5개년 계산
HITL: 조문과 검수 근거에 없는 대상 고유값 확정
```

## v2 지원 경로

| 비용항목 | 산식 |
|---|---|
| 직급별 보수 | `Σ(직급별 순증인원 × 직급별 보수)` |
| 평균단가 보수 | `순증인원 × 1인당 연간보수` |
| 기관부담금 | `보수총액 × 기관부담률` |
| 기본경비 | `보수총액 × 기본경비비율` 또는 `순증인원 × 1인당 기본경비` |
| 자산취득비 | `순증인원 × 1인당 자산취득비`(최초 1회) |
| 단일 위원회 | `지급대상인원 × 연간횟수 × 회의수당` |
| 복수·지역위원회 | `설치개수 × 지급대상인원 × 연간횟수 × 회의수당` |
| 조직·위원회 연간 운영비 | 검수된 동일범위 연간예산 또는 대상별 입력 |

## 근거 정책

- 대상 조문·공식 기준·사용자 확정값이 선례보다 우선한다.
- 선례 피연산자는 하나의 `profile_key`에서만 가져온다.
- `target_specific`, `do_not_transfer`는 새 의안으로 이전하지 않는다.
- `comparable_only`, `scope_check_required`는 조직형태·적용범위 게이트가
  통과해야 한다.
- `review_status=verified`가 아닌 값은 운영 자동계산에 사용하지 않는다.
- 진단 모드에서 candidate 근거를 사용하면 결과에 경고를 반드시 남긴다.
- 요청에 `target_bill_no` 또는 `target_bill_id`가 있으면 해당 프로필을
  선택하더라도 `TARGET_PROFILE_EXCLUDED`로 차단한다.
- `cutoff_date`가 있으면 발의일이 이후인 프로필을 차단하고, 발의일이 없는
  프로필도 시간축 검증에서 사용하지 않는다.

## 실행

```bash
python3 -m backend.scripts.run_org_admin_resolver \
  backend/examples/org_admin_request.json
```

## 현재 한계

- Sidecar 3,178건은 모두 candidate이므로 아직 운영 자동확정에 쓸 수 없다.
- 인건비는 기존 `organization.py`의 완결 인력비 묶음 선례 경로와 연결해야 한다.
- 새 의안 일반화 성능은 시간축 블라인드 홀드아웃으로 별도 평가해야 한다.
- 원문에서 순증인원·민간위원 수·회의횟수처럼 대상 고유 규모가 빠진 경우
  금액을 자동 확정하지 않는다. 대상 제외 홀드아웃 결과는
  `docs/dev_log/ORG_ADMIN_TARGET_EXCLUDED_HOLDOUT.md`에 기록한다.

## 2026-09-11 로컬 검증

- Resolver·Sidecar 단위 테스트 27개 통과
- 복수위원회 과거 7건 모두 공식값 5% 이내, MAPE 0.721%
- `17개 시·도 + 226개 시·군·구`를 243개로 정규화해 연 2,916,000천원 계산
- 해당 공식값 2,940,000천원 대비 오차 0.82%

기존 PDF end-to-end 회귀는 현재 작업트리에서 7건 중 3건만 통과했다.
실패 4건은 계산기가 아니라 위원회·계획·전담담당관을 잘못 분류한 기존
LLM/캐시 입력 계층의 회귀다. 따라서 v1은 AI 구조화 결과가 바르다는 전제의
`post-AI resolver`이며, end-to-end 완성으로 표현하지 않는다.
