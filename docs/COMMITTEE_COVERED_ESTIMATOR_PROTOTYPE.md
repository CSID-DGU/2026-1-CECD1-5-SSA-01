# 위원회 근거 보유 건 실행 프로토타입

## 목표

DB에 근거가 있는 건만 자동 계산하고, 근거가 없거나 대상 구조가 바뀐 건은
Human-in-the-loop로 보낸다. 검색 성공을 계산 성공으로 간주하지 않는다.

`backend/committee_covered_estimator.py`는 다음 순서로 판정한다.

1. 동일 법안 이력이나 템플릿 계보로 완결 선례를 찾는다.
2. 선례의 위원수·상임위원·지원조직이 대상 법안과 같은지 검사한다.
3. 선례 TAG의 산식, 변수, 연간 금액의 내부 일관성을 검사한다.
4. 대상 법안에 명시된 유효기간을 적용해 5개년 시계열을 만든다.
5. 하나라도 부족하면 금액을 만들지 않는다.

이 엔진의 판정 로직은 `tag_pipeline.py`를 바꾸지 않고
`committee_evidence_adapter.py`를 통해 위원회 전용 API에 연결했다.
기존 미리보기 계산과 자동 게시 가능한 검증 선례를 섞지 않는다.

## 제품 연결: 세 가지 근거 경로

| 경로 | 자동 금액 확정 | 화면 행동 |
|---|---:|---|
| 검증된 완전 선례 | 예 | 산식·항목·선택 의안·연간/시계열 금액을 바로 표시 |
| 구조적 유사 선례 | 아니오 | 최대 3개 후보와 추천 변수를 보여주고 사용자 확인 후 재계산 |
| 근거 부족 | 아니오 | 없는 필수값만 입력받아 Python으로 재계산 |

전용 UI는 초록·노랑·빨강의 세 상태로 이 경로를 먼저 보여준다.
조문과 기존 RAG 세부 근거는 기본 화면에서 숨기고 필요할 때만 펼쳐본다.

## 모델 장애 fallback

위원회 실체 그룹화는 LLM을 보조적으로 쓰지만, 호출이 실패해도
원문 규칙으로 설치·구성·필수 심의 조문을 그룹화한다. 기존 위원회에
새 심의 의무를 부과하는 경우는 공공기관 소속·설치 근거가 같은 원문에
있을 때만 비용 사건으로 받아 민간단체 내부 위원회 오탐을 막는다.

실제 `2215013`에서 LLM과 외부 임베딩을 강제로 끄고도 다음을 확인했다.

- 원문 fallback으로 `건축위원회` 1건 탐지
- 선행 의안 `2213418` 선택
- `28,426건 ÷ 23건 × 300만원 = 3,707,739천원` 일회성 계산
- UI 경로 `verified`, 자동 계산 상태 `computed`

## 알려진 완결 선례 회귀 12건

| 지표 | 결과 |
|---|---:|
| 프로토타입 계산 | 11건 |
| 구조 변경으로 차단 | 1건 |
| 계산 11건 정상연도 금액 20% 이내 | 11/11 |
| 계산 11건 5개년 합계 20% 이내 | 11/11 |

정상연도 금액은 11건 모두 정답과 일치했다. 시계열 합계는 9건이 일치했고,
2건은 시행일이 회계연도 중간에 걸리는 부분연도 문제로 각각 약 15% 차이가 났다.

`2216353`은 기존 해결기가 `2215377`을 완결 선례로 판정했지만, 대상에는
새로운 위원장·상임위원 보수가 추가되었다. 프로토타입은
`standing_member_payroll_missing`으로 자동 계산을 차단했다.

## 위원회 50건 회귀

| 판정 | 결과 |
|---|---:|
| 즉시 자동 게시 가능 | 1건 |
| 산식·정상연도 금액은 완결, 시행일 검토 필요 | 1건 |
| 구조 변경으로 전체 산식은 차단, 기존 비용항목은 참고 가능 | 1건 |
| 일부 비용항목 후보는 있지만 관계 검증·전체 계산은 불가 | 5건 |
| 관련 법안만 확인, 재사용 가능한 비용항목은 미확인 | 9건 |
| 후보는 있지만 이전 근거 관계를 검증하지 못함 | 33건 |
| 거짓 자동계산 | 0건 |

`blocked=48`은 “DB에 참고할 내용이 전혀 없다”는 뜻이 아니다.
그중 1건은 검증된 선례의 기존 비용항목을 부분 근거로 보여줄 수 있고,
5건은 비용항목 후보를 검토용으로 제시할 수 있다. 또한 9건은
관련 법안까지만 확인된다. 나머지 33건도 “선례 부재”가 아니라
“현재 구조화된 근거로는 이전 관계를 입증하지 못함”으로 해석한다.

### 2215013

- 선례: `2213418`
- 산식: `28,426건 ÷ 23건 × 300만원`
- 프로토타입: 3,707,739천원
- 정답: 3,708,000천원
- 오차: -0.01% 미만
- 산식과 변수 5개를 선례 TAG에서 함께 가져왔고, 대상 법안의 1년 유효기간을
  시계열에 적용했다.

### 2217718

- 선례: `2213320`
- 산식: `민간위원 6명 × 20만원 × 연 3회`
- 정상연도 프로토타입/정답: 모두 3,600천원
- 5개년 프로토타입: 18,000천원
- 5개년 정답: 15,600천원
- 오차: +15.4%
- 정상연도 산식·변수는 완결됐지만 첫해 4개월분을 결정할 실제 시행일이 없다.
  따라서 `ready_for_auto_publish=false`로 표시하고 시행일만 사용자에게 확인한다.

## 현재 판정

알려진 근거 보유 건에 대한 **정상연도 산식 실행 프로토타입은 통과**했다.
다만 이 12건은 개발·회귀셋이므로 일반화 성능을 입증하지는 않는다.

프로덕션 합격 기준은 다음과 같다.

- 구조를 고정한 뒤 새 완결 선례 최소 20건 블라인드 평가
- 자동 계산 precision 95% 이상
- 자동 계산 건 중 20% 오차 이내 90% 이상
- 거짓 자동 계산 0건을 목표로 유지
